TRIP-06-P01 글로벌 법인별 관리 — 마스터 그리드
Page ID: TRIP-06-P01
Definition: 해외 법인의 출장 시스템, 기안 항목, 등급 규정을 한 표로 조회하는 메인 화면
Path: 업무관리자 > 출장 관리 > 글로벌 법인별 관리
정책 정보
■ 주요 정책
• 기존 출장 관리에 추가되는 메뉴는 "글로벌 법인별 관리" 탭 1개
• 기본 화면은 해외 법인의 값을 보여주는 마스터 그리드
• HYB 및 국내 법인은 Redcap BTMS 를 사용하며 이 메뉴에 노출하지 않음
• HBA·HBL·HBJ 는 Concur (AMEX GBT) 사용 법인으로 AMEX GBT 와 하이브넷 모두 세팅 필요
• HBC·HBI 등 출장 시스템 미사용 법인은 "미사용"으로 노출하고 [관리] 비활성. AMEX GBT 합류 시 오픈
• 수정은 [관리] 모달에서만 수행. 모든 수정은 컨펌 팝업을 거쳐 저장하고 변경 이력에 기록
• 법인 목록은 인사정보 연동 결과를 그대로 사용(추가·삭제 불가)
• AMEX GBT 세팅 담당자(HYB TnM)가 이 화면의 관리자
■ 확인 필요 사항
• 출장 시스템 구분 값을 어디에서 관리할지(프로토타입: 시스템 설정 값, 화면에서 변경 불가)

정책 정보
■ 주요 정책
• 항목은 출장 예산 / 법인카드 실시간 한도증액 / 출장 근태 신청 3종 고정
• OFF인 섹션은 구성원 기안 화면에서 영역 자체를 노출하지 않음
• 저장 즉시 신규 기안부터 적용. 결재 진행 중 기안은 작성 당시 설정 유지

• 신규 법인의 기본값은 전부 OFF
• HBA·HBL·HBJ 구성원도 하이브넷에서 출장 기안을 작성(예약은 Concur). 항목은 순차적으로 확대

TRIP-06-M02 법인 관리 — 등급 규정
Page ID: TRIP-06-M02
Definition: 법인별 구성원 등급(연동 코드)과 직책 매핑, 개인 예외 지정을 관리하는 탭
Path: 업무관리자 > 출장 관리 > 글로벌 법인별 관리 > [관리] > 등급 규정 (모달)
정책 정보
■ 주요 정책
• 등급은 법인별로 정의하고 인사정보 직책에 매핑해 자동 판정
• 한 직책은 한 등급에만 매핑. 겸직인 경우 본직 기준
• 미할당 직책의 구성원은 최종 등급이 없어 OBT 사용 불가(모든 직책 할당 필요)
• 연동 코드 = AMEX GBT(Egencia)에 등록된 traveler group 값. 필수, 법인 내 중복 불가, 대소문자 구분
• 등급명은 표시용이며 변경해도 연동에 영향 없음. 연동은 연동 코드로만 식별
• GBT에서 사용 중인 등급도 삭제·이름 변경·코드 변경 가능(저장 시 GBT 값 일치 안내)
• 개인 예외 지정은 적용 기간 동안 직책 매핑보다 우선
• 예외 구성원이 퇴사하거나 다른 법인으로 이동하면 예외를 자동 해제하고 변경 이력에 기록
• 발령으로 직책만 바뀐 구성원의 예외 지정은 유지(관리자 관리)
• 예외 종료 임박 알림 없음
■ 확인 필요 사항
• 인사정보 매핑 키가 직책인지 직급인지, 법인별 코드 체계

Page ID: TRIP-06-M02-1
Definition: 개인 예외 지정 대상 구성원을 조직도 트리에서 찾아 선택하는 창
Path: 업무관리자 > 출장 관리 > 글로벌 법인별 관리 > [관리] > 등급 규정 (모달)
정책 정보
■ 주요 정책
• 개인 예외 지정 대상은 조직도 트리에서 선택 필요
• 관리 중인 법인의 조직도만 노출(다른 법인 구성원 선택 불가)
• 구성원의 소속·직책·이메일은 인사정보 값을 그대로 사용
• 선택 완료 시점에는 저장되지 않음. 관리 모달 [저장] → 컨펌 팝업을 거쳐야 반영
화면 설명 및 디스크립션
❶ 검색
• 플레이스홀더 : 이름, 이메일
• 키워드 : 이름, 이메일(부분 일치, 대소문자 무시, 30자)
• 기타
: 입력 즉시 반영. 검색어가 있으면 조직 선택과 무관하게 법인 전체에서 조회
: 결과가 없으면 "검색 결과가 없습니다." 문구 노출
❷ 조직도 트리
• 구성 : 법인 › 상위 조직 › 하위 조직 트리, 조직별 구성원 수(하위 포함)
• 기능
: 조직 선택 → 우측에 해당 조직(하위 포함) 구성원 표기
: 선택된 조직 재선택 → 하위 접기/펼치기
• 디폴트 : 법인(최상위) 선택, 1단계 조직 펼침
❸ 구성원 목록
• 구성 : 체크박스, 이름·이메일, 조직, 매핑 등급
• 기능 : 체크 → 하단 선택 칩에 추가(복수 선택), 칩의 ✕ → 선택 해제
• 기타
: 이미 예외가 지정된 구성원은 비활성(선택 불가)
: 조직·검색을 바꿔도 선택 유지
❹ 하단 버튼
• 구성 : [취소][선택 완료]
• 기능
: [취소] 선택 → 모달 닫기
: [선택 완료] 선택 → 개인 예외 지정 표에 순서대로 "신규" 행 추가 후 모달 닫기
• 기타
: 선택된 구성원이 없으면 [선택 완료] 버튼 비활성화 상태

TRIP-06-M01-1 변경 내용 확인
Page ID: TRIP-06-M01-1
Definition: 관리 모달의 변경 내역을 확인하고 최종 저장하는 컨펌 팝업
Path: 업무관리자 > 출장 관리 > 글로벌 법인별 관리 > [관리] > [저장] (모달)
정책 정보
■ 주요 정책
• 모든 수정은 이 팝업의 [저장]으로만 반영
• 모든 수정은 항상 즉시 적용
• 등급 규정·개인 예외가 바뀌면 저장 직후 해당 법인 구성원의 최종 등급을 AMEX GBT로 전송
• 저장 1회에 저장 번호(S-0000)를 발급하고 변경 1건당 이력 1행 기록
• 변경 사유는 모든 저장에 필수
화면 설명 및 디스크립션
❶ 헤더
• 구성 : 제목, 법인 코드·법인명
❷ 변경 내역
• 구성 : 구분(기안 항목/등급 규정/개인 예외), 변경 내용, 변경 전 → 변경 후
• 기타 : 2개 탭의 변경을 한 번에 표기
: 표의 1행이 변경 이력 1건
❸ AMEX GBT 안내
• 구성 : 안내 문구
• 기타 : 등급 추가·삭제, 연동 코드 변경이 포함될 때만 노출
❹ 변경 사유
• 플레이스홀더 : 변경 이력에 함께 기록됩니다 (필수, 200자 이내)
• 기타 : 비우고 저장 시 입력란 아래 오류 문구 노출
❺ 하단 버튼
• 구성 : [취소][저장]
• 기능
: [취소] 선택 → 관리 모달로 복귀(입력 유지)
: [저장] 선택 → 변경 내용 저장 및 모달 닫기, 그리드 리로드

TRIP-06-P03 구성원 최종 등급
Page ID: TRIP-06-P03
Definition: AMEX GBT로 전송되는 구성원별 최종 등급과 전송 상태를 조회하는 화면
Path: 업무관리자 > 출장 관리 > 글로벌 법인별 관리 > [구성원 최종 등급]
정책 정보
■ 주요 정책
• 여비규정은 AMEX GBT(Egencia)에서 세팅하고, 하이브넷은 법인·구성원·최종 등급만 전달
• 전달 항목 : 법인 코드, 이메일(SSO 계정과 동일), 최종 등급의 연동 코드
• 최종 등급 = 조회 시점에 적용 중인 개인 예외 > 직책 매핑(법인 현지 시간 기준)
• 연동 방향 : 하이브넷이 Egencia User Sync API(SCIM 2.0)를 호출해 전송. Egencia 는 하이브넷을 조회하지 않음
• 전송 시점 : 등급 규정·개인 예외 저장 직후, 개인 예외 시작·종료일이 도래하는 법인 현지 자정, 인사정보 동기화로 직책·소속이 바뀐 때
• 인증 : OAuth 2.0 client credentials(Egencia 발급 Client ID/Secret)
• 미할당 직책 구성원은 최종 등급이 없어 전송 대상에서 제외(OBT 사용 불가)
• 조회 대상은 출장 시스템이 Concur (AMEX GBT)인 법인
■ 확인 필요 사항
• User Sync API 로 traveler group 을 지정할 수 있는지와 정확한 필드명(Egencia 담당자 확인 필요)
• 전송 실패 시 자동 재시도 횟수·간격과 관리자 알림 여부
• 엑셀 다운로드 · 페이지네이션 필요 여부
화면 설명 및 디스크립션
❶ 목록
• 구성 : 번호, 법인, 구성원(이름·이메일), 소속·직책, 매핑 등급, 개인 예외, 최종 등급(연동 코드), AMEX GBT 전송
• 기능 : [← 이전] 선택 → TRIP-06-P01 로 이동
• 기타 : 조회 기준일(법인 현지 시간) 표기. 건수는 필터 결과 기준
❷ 필터 · 검색
• 구성 : 법인 Select, 구분 Select(개인 예외 적용/등급 미할당/전송 실패), 통합 검색
• 키워드 : 이름, 이메일(부분 일치, 30자)
• 기타 : 입력 즉시 반영. 결과가 없으면 "조건에 맞는 구성원이 없습니다." 문구 노출
❸ 개인 예외
• 구성 : 적용 중 칩, 적용 기간
• 기타 : 조회 시점에 적용 중인 예외만 표기(예정·만료는 "-")
❹ 최종 등급
• 구성 : 등급명, 연동 코드
• 기타 : 미할당 직책이면 "등급 없음 · OBT 사용 불가" 표기
❺ AMEX GBT 전송
• 구성 : 전송 완료/전송 실패 칩, 마지막 전송 일시, [재전송]
• 기능 : [재전송] 선택 → 해당 구성원의 최종 등급 즉시 재전송
• 기타 : 등급 없음 구성원은 "전송 대상 아님" 표기
