관리 모달 — 등급 규정

TRIP-ADM-POL-02b · 법인별 구성원 등급과 직책 매핑, 개인 예외 지정을 표 안에서 바로 추가·수정·삭제한다.

화면 상세

1
관리 모달
그리드의 [관리]로 호출. 제목에 법인 코드, 부제에 법인명·국가·기준 통화·구성원 수(인사정보 연동, 읽기 전용). 탭 3개로 구성하며, 변경이 있는 탭에는 주황 점을 표시한다. 탭을 오가도 입력은 유지된다.
4
구성원 등급 표
  • + 등급 추가: 표 맨 아래에 빈 행 추가(첫 등급은 자동으로 기본 등급).
  • 등급명: 필수, 20자, 법인 내 중복 불가. 설명: 선택, 60자.
  • ▲▼로 순서를 바꾸며, 이 순서가 여비규정 표의 행 순서가 된다.
  • 삭제: 개인 예외 지정의 적용 등급으로 쓰이고 있으면 삭제 불가(토스트). 기본 등급은 다른 등급을 기본으로 지정한 뒤 삭제.
  • 등급 추가·삭제·이름 변경은 같은 모달의 여비규정 표(등급별 차등 항목)에 즉시 반영된다. 추가된 등급의 값은 미정의.
5
매핑 직책
인사정보 직책을 칩으로 표시. + 직책 선택 상자에는 아직 어느 등급에도 매핑되지 않은 직책만 나온다(한 직책은 한 등급에만). 칩의 ×로 해제. 미매핑 직책은 표 아래에 개수·목록과 함께 "기본 등급 적용"으로 안내한다.
6
기본 등급
라디오로 법인당 1개 지정(필수). 어느 등급에도 매핑되지 않은 직책의 구성원에게 적용된다.
7
개인 예외 지정
  • + 조직도에서 구성원 선택: 등급이 2개 이상일 때 활성. 조직도 선택 팝업(TRIP-ADM-POL-02b-1)을 띄우고, 선택한 구성원 수만큼 행이 추가된다. 추가된 행에는 "신규" 배지와 소속·직책·매핑 등급이 자동 표시되고 시작일은 오늘로 채워진다.
  • 적용 등급: 매핑 등급과 같은 등급은 선택 불가. 사유: 필수, 100자.
  • 기존 건은 구성원을 바꿀 수 없고 적용 등급·사유·기간만 수정한다. 삭제는 행을 제거한다.
8
적용 기간
시작일 필수, 종료일 선택(비우면 무기한). YYYY.MM.DD, 종료일은 시작일 이후. 종료일이 지난 건은 "만료" 배지를 표시하고 직책 매핑 등급으로 돌아간다. 과거 시작일(소급)도 허용.
15
하단 영역
  • 이 법인 변경 이력: 해당 법인으로 필터된 변경 이력 화면으로 이동(변경이 있으면 닫기 확인).
  • 저장: 변경이 없으면 비활성. 누르면 입력 검증 후 변경 내용 확인 팝업(TRIP-ADM-POL-03)을 띄운다.
  • 취소/×/Esc: 변경이 있으면 닫기 확인을 띄운다.

정책

  • 등급은 법인별로 정의하고 인사정보 직책에 매핑해 자동 판정한다. 개인 예외 지정은 적용 기간 동안 직책 매핑보다 우선한다.
  • 등급 기준 변경은 여비규정 표에 즉시 반영한다(추가=미정의 행, 삭제=행과 값 삭제, 이름 변경=값 유지).
  • 입력 검증은 [저장] 시점에 한 번에 한다.

확인 필요 사항

매핑 키 — 인사정보에서 가져오는 값이 직책인지 직급인지, 법인별 코드 체계 확인 필요.
조직도 컴포넌트 — HYBENET 공통 조직도 컴포넌트를 재사용하는지, 관리 중인 법인의 조직만 보여주는지(프로토타입 가정), 겸직·파견 구성원을 어느 법인 소속으로 볼지 확인 필요.
예외 지정 승인 — 관리자 등록만으로 충분한지, 별도 승인·증빙이 필요한지.
직책 변경 시 예외 지정 유지 여부 — 발령으로 직책이 바뀐 구성원의 예외 지정 처리.
