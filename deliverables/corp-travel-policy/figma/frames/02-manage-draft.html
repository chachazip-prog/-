관리 모달 — 기안 항목 관리

TRIP-ADM-POL-02a · 구성원 출장 기안 화면의 섹션 3종 사용 여부를 법인별로 설정한다.

화면 상세

1
관리 모달
그리드의 [관리]로 호출. 제목에 법인 코드, 부제에 법인명·국가·기준 통화·구성원 수(인사정보 연동, 읽기 전용). 탭 3개로 구성하며, 변경이 있는 탭에는 주황 점을 표시한다. 탭을 오가도 입력은 유지된다.
2
항목 3종
출장 예산 / 법인카드 실시간 한도증액 / 출장 근태 신청. 항목은 고정이며 추가·삭제·순서 변경은 없다. 토글을 바꾸면 항목명 옆에 "변경" 표시가 붙고, 보조 문구가 ON이면 연동 시스템, OFF이면 구성원 화면 영향으로 바뀐다. 토글은 즉시 저장되지 않는다.
3
적용 안내
저장 즉시 신규 기안부터 적용, 결재 진행 중 기안은 작성 당시 설정 유지, OFF 전환 시 임시저장 기안 삭제. 삭제 건수는 컨펌 팝업에서 다시 경고한다.
15
하단 영역
  • 이 법인 변경 이력: 해당 법인으로 필터된 변경 이력 화면으로 이동(변경이 있으면 닫기 확인).
  • 저장: 변경이 없으면 비활성. 누르면 입력 검증 후 변경 내용 확인 팝업(TRIP-ADM-POL-03)을 띄운다.
  • 취소/×/Esc: 변경이 있으면 닫기 확인을 띄운다.

정책

  • OFF인 섹션은 구성원 기안 화면에서 영역 자체를 노출하지 않는다.
  • 연동 여부와 관계없이 모든 법인에서 ON을 막지 않는다.
  • 신규 법인의 기본값은 3개 모두 OFF(가정).

확인 필요 사항

연동 미비 법인에서 ON — 섹션이 열렸을 때 불러오기·신청 버튼의 동작(오류 안내 등) 확인 필요.
신규 연동 법인 기본값 — 전부 OFF로 가정했다. 확정 필요.
