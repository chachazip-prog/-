TRIP-06-P01 글로벌 법인별 관리 — 마스터 그리드
Page ID: TRIP-06-P01
Definition: 해외 법인의 출장 시스템, 기안 항목, 등급 규정을 한 표로 조회하는 메인 화면
Path: 업무관리자 > 출장 관리 > 글로벌 법인별 관리
정책 정보
■ 주요 정책
• 기존 출장 관리에 추가되는 메뉴는 "글로벌 법인별 관리" 탭 1개
• 기본 화면은 해외 법인의 값을 보여주는 마스터 그리드
• HYB 및 국내 법인은 Redcap BTMS 를 사용하며 이 메뉴에 노출하지 않음
• HBA·HBL·HBJ 는 Concur (AMEX GBT) 사용 법인으로 AMEX GBT 와 하이브넷 모두 세팅 필요
• HBC·HBI 등 출장 시스템 미사용 법인은 "미사용"으로 노출하고 [관리] 비활성. AMEX GBT 합류 시 오픈
• 수정은 [관리] 모달에서만 수행. 모든 수정은 컨펌 팝업을 거쳐 저장하고 변경 이력에 기록
• 법인 목록은 인사정보 연동 결과를 그대로 사용(추가·삭제 불가)
• AMEX GBT 세팅 담당자(HYB TnM)가 이 화면의 관리자
■ 확인 필요 사항
• 출장 시스템 구분 값을 어디에서 관리할지(프로토타입: 시스템 설정 값, 화면에서 변경 불가)
화면 설명 및 디스크립션
❶ 검색/조회 조건
• 구성 : 출장 시스템 Select(전체, Concur (AMEX GBT), 미사용), 통합 검색
• 키워드 : 법인 코드, 법인명
• 플레이스홀더 : 법인 코드, 법인명 검색
• 기타 : 입력 즉시 반영. 결과가 없으면 "검색 결과가 없습니다." 문구 노출
❷ 그리드
• 구성 : 번호, 법인, 출장 시스템, 구성원 수, 기안 항목(출장 예산, 법인카드 실시간 한도증액, 출장 근태 신청), 등급 규정(등급, 개인 예외, 미할당 직책), 최종 수정, [관리]
❸ 법인
• 구성 : 법인 코드, 법인명, 국가, 구성원 수
• 기타 : HAM 데이터 연동(읽기 전용) 값
: HAM 데이터 기준 순서 노출
❹ 출장 시스템
• 구성 : Concur (AMEX GBT) / 미사용 칩
• 기타 : 미사용 법인은 기안 항목·등급 규정 칸을 합쳐 안내 문구 표기
❺ 기안 항목
• 구성 : 출장 예산, 법인카드 실시간 한도증액, 출장 근태 신청 ON/OFF 칩
• 기타 : 조회 전용
❻ 등급 규정
• 구성 : 등급명 칩(등록 순서), 개인 예외 건수, 미할당 직책 수
• 기타
: 개인 예외 건수는 적용 중 + 예정 기준(만료 제외)
: 등급이 없으면 "미등록", 미할당 직책이 있으면 빨간 칩 표기
❼ 최종 수정 · 관리
• 구성 : 최종 저장 일자, 수정자, [관리]
• 기능 : [관리] 선택 → 각 법인별 TRIP-06-M01 호출
• 기타 : 미사용 법인은 [관리] 비활성
❽ 구성원 최종 등급 버튼
• 기능 : 선택 → TRIP-06-P03 로 전환
❾ 변경 이력 버튼
