정책 정보
■ 주요 정책
• 여비규정은 기준 정보 관리 + 구성원 안내용. 출장 계획서 자동 검증·차단, 규정 예외 신청 연동 없음
• 개정 버전 목록 없이 현재 값 1벌만 편집. 과거 값은 변경 이력에서 확인
• 지역 구분은 별도 마스터 없이 항목별 열 이름으로 관리
• 규정을 공유하는 법인(HBA·HBL)도 각각 등록. 복사는 1회성(연결 없음)
• HYB 값은 화면 예시용 샘플, HBA·HBL·HBJ 는 유첨 규정 문서 기준
■ 확인 필요 사항
• 지역 열과 출장지 관리 마스터의 매핑 필요 여부
• 열마다 통화가 다른 항목(HBJ 식비 ¥/₩/US$)의 칸 단위 통화 지정
• 구성원 안내 노출 위치(출장 계획서/기안 화면)
• 항목명·안내 문구의 다국어(영/일) 등록

• 기능 : 분류 선택 → 해당 분류의 항목만 노출

❹ 항목
• 구성 : 사용 토글, 항목명, 지급 방식, 통화, 단위, 등급별 차등, 값 표, 적용 조건, 구성원 안내, [항목 삭제]
