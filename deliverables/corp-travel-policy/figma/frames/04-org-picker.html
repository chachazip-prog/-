조직도 구성원 선택 팝업

TRIP-ADM-POL-02b-1 · 개인 예외 지정 대상 구성원을 조직도 트리에서 찾아 선택한다. 등급 규정 탭의 [+ 조직도에서 구성원 선택]으로 호출한다.

화면 상세

1
팝업
관리 모달 위에 겹쳐 뜬다. 관리 중인 법인의 조직도만 보여준다(다른 법인 구성원은 선택 불가). 열릴 때 최상위(법인)와 1단계 조직이 펼쳐져 있고 법인 전체 구성원이 목록에 나온다. ×·취소·Esc는 선택을 버리고 닫는다.
2
검색
이름 또는 사번 부분 일치(30자, 대소문자 무시, 입력 즉시 반영). 검색어가 있으면 조직 선택과 무관하게 법인 전체에서 찾고, 지우면 선택한 조직의 목록으로 돌아간다. 결과가 없으면 "검색 결과가 없습니다."
3
조직 트리
법인 › 상위 조직 › 하위 조직 순의 트리. 조직명 옆 숫자는 하위 조직을 포함한 구성원 수. 조직을 누르면 선택(검정 반전)되고 하위가 펼쳐지며, 선택된 조직을 다시 누르면 접힌다. 조직을 선택하면 하위 조직 구성원까지 우측 목록에 나온다.
4
구성원 목록
체크박스로 여러 명을 선택할 수 있다. 행마다 이름·사번, 조직 경로·직책, 현재 매핑 등급을 보여준다. 이미 개인 예외가 지정된(또는 이번에 추가해 둔) 구성원은 "지정됨" 배지와 함께 비활성. 선택한 구성원은 하단에 칩으로 모아 보여주고 ×로 해제한다. 조직·검색을 바꿔도 선택은 유지된다.
5
선택 완료
1명 이상 선택 시 활성. 누르면 팝업을 닫고 개인 예외 지정 표에 선택한 순서대로 행을 추가한 뒤 첫 신규 행의 적용 등급으로 포커스를 옮긴다. 이 시점에는 저장되지 않으며, 적용 등급·사유를 입력하고 관리 모달의 [저장] → 컨펌 팝업을 거쳐야 반영된다.

정책

  • 개인 예외 지정 대상은 조직도 트리에서 선택한다. 직접 입력은 받지 않는다.
  • 구성원의 소속·직책은 인사정보 값을 그대로 쓰며 이 화면에서 수정하지 않는다.

확인 필요 사항

조직도 컴포넌트 — HYBENET 공통 조직도 컴포넌트 재사용 여부와 조직 단계(depth) 표시 범위.
조회 범위 — 관리 중인 법인만 보여주도록 가정했다. 겸직·파견 구성원의 소속 법인 기준 확인 필요.
퇴직·휴직자 — 조직도에서 제외할지, 기존 예외 지정은 어떻게 처리할지.
