저장하지 않은 변경 3건이 사라집니다.

관리 모달 — 여비규정 설정

TRIP-ADM-POL-02c · 교통 / 숙박 / 일비·식비 / 기타 4개 분류로 항목과 값을 입력한다. 기준 정보 관리·구성원 안내용이며 자동 검증·차단은 없다.

화면 상세

1
관리 모달
그리드의 [관리]로 호출. 제목에 법인 코드, 부제에 법인명·국가·기준 통화·구성원 수(인사정보 연동, 읽기 전용). 탭 3개로 구성하며, 변경이 있는 탭에는 주황 점을 표시한다. 탭을 오가도 입력은 유지된다.
9
여비규정 설정
원문 문서(선택, 파일명 80자 — 실제는 파일 첨부)를 함께 관리한다. 개정 버전 목록은 두지 않고 현재 값 1벌만 편집한다. 과거 값은 변경 이력에서 확인한다.
10
분류 선택
교통 / 숙박 / 일비·식비 / 기타. 분류별 항목 수를 함께 표시하고, 선택한 분류의 항목만 아래에 나열한다. 값이 빈 칸이 있으면 우측에 "미정의 N칸"을 주황색으로 표시한다.
11
항목 블록
  • 사용 토글: OFF면 값 영역을 접고 구성원에게 안내하지 않는다(값은 보존).
  • 항목명(필수, 20자), 지급 방식(등급 기준 / 한도 내 실비 / 정액 지급 / 실비), 통화(한도·정액일 때만), 단위(30자).
  • 등급별 차등 체크: 켜면 행이 등급 목록으로, 끄면 "전체 구성원" 1행으로 바뀐다(끄면 첫 행 값만 남김). 등급이 없는 법인은 비활성.
  • 열: 지역·조건 등 구분을 자유롭게 입력한다(열 이름 24자, 중복 불가). + 열로 추가, ×로 삭제(최소 1열).
  • 칸: 숫자만 입력하면 금액(통화 기호·천 단위 구분), 문자가 섞이면 문구로 저장. 빈 칸은 주황 테두리 + "미정의".
  • 적용 조건(80자)·구성원 안내(300자)는 선택.
12
항목 추가 · 삭제
+ (분류) 항목 추가는 현재 분류 맨 아래에 빈 항목(한도 내 실비, 1행 1열)을 만든다. 항목 삭제는 즉시 작업본에서 제거하며 저장 전에는 취소로 되돌릴 수 있다. 항목이 하나도 없는 법인에는 표준 항목으로 시작(항공·철도·숙박·식비·출장 수당·통신비)을 제공한다.
13
다른 법인 규정 복사
적용 중 규정이 있는 다른 법인을 골라 항목·값을 통째로 복사해 온다(현재 작업본을 대체, 확인 필요). 1회성 복사이며 법인 간 연결은 없다. 등급별 차등 항목의 행은 이 법인의 등급 순서대로 값을 옮기고, 등급 수가 다르면 남는 값은 버리고 모자란 칸은 미정의로 둔다.
14
적용 예정 배너
적용일을 지정해 저장한 변경이 있을 때만 노출. 적용 예정본(편집 가능) / 현재 적용 값(읽기 전용)을 전환해 볼 수 있고, 예정 취소는 확인 팝업을 거쳐 예정 변경을 폐기한다. 적용일이 되면 시스템이 예정본을 현재 값으로 바꾼다(프로토타입은 자동 전환 미구현).
15
하단 영역
  • 이 법인 변경 이력: 해당 법인으로 필터된 변경 이력 화면으로 이동(변경이 있으면 닫기 확인).
  • 저장: 변경이 없으면 비활성. 누르면 입력 검증 후 변경 내용 확인 팝업(TRIP-ADM-POL-03)을 띄운다.
  • 취소/×/Esc: 변경이 있으면 닫기 확인을 띄운다.

정책

  • 여비규정은 기준 정보 관리 + 구성원 안내용이다. 출장 계획서 자동 검증·차단, 규정 예외 신청 연동은 하지 않는다.
  • 지역 구분은 별도 마스터 없이 항목별 열 이름으로 관리한다(간소화). 법인마다, 항목마다 지역 구분이 달라도 된다.
  • 규정을 공유하는 법인(HBA·HBL)도 각각 등록하며, 복사는 1회성이다.
  • HYB 값은 화면 예시용 샘플, HBA·HBL·HBJ는 유첨 규정 문서 기준 값이다.

확인 필요 사항

지역 열과 출장지 마스터 연결 — 간소화를 위해 지역을 자유 입력 열로 바꿨다. 구성원 안내 시 출장지(국가·도시)에 맞는 열을 자동으로 골라 보여주려면 출장지 관리와의 매핑이 다시 필요하다.
항목 안에 통화가 섞이는 경우 — HBJ 식비(¥/₩/US$)처럼 열마다 통화가 다른 경우는 문구로 입력하게 했다. 칸 단위 통화 지정이 필요한지 확인 필요.
구성원 안내 노출 위치 — 출장 계획서·기안 화면 중 어디에 어떤 형태로 보여줄지 미정.
다국어 표기 — 항목명·안내 문구를 영어·일본어로 함께 등록할지.
