# 한양 주막 — 기획서 v0.1 (초안)

작성일 2026-11-21 · 상태: 오너 검토 전 초안 · 수치는 모두 가정값(검증 필요 표시)

## 1. 한 줄
한양 성문 밖 낡은 주막을 물려받아, 오가는 손님에게 밥과 술을 내고 그들의 사연을 들으며 주막과 마을을 키우는 아늑한 운영 게임.

- 판타지: “조선의 단골집 주인이 되어, 손님의 인생을 곁에서 지켜본다.”
- 역사의 역할: 배경과 손님의 사연. 큰 사건은 손님이 전해 주는 ‘소문’으로 흘러가고, 플레이어는 역사를 바꾸지 않는다.
- 레퍼런스(장르만): Stardew Valley·Coffee Talk·Good Pizza, Great Pizza 같은 아늑한 운영·대화 게임. 이들의 화풍·IP는 쓰지 않는다.

## 2. 대상과 언어
| 대상 | 끌리는 지점 |
|---|---|
| 해외 한류 팬·한국어 학습자 | 사극의 일상, 한국 음식, 손님과의 대화 |
| 방한 관광객 | 다녀온 한양(서울)의 옛 모습, 기념이 되는 소품 수집 |
| 한국인 | 사극 같은 사연, 익숙한 음식, 힐링 |

- 출시 언어: 한국어·영어·일본어(번역 초안은 AI, 사람 감수). 판매가 확인된 뒤 중국어(번체·간체).
- 연령 등급 목표: 전체이용가 또는 12세. 술은 ‘주막의 음식’으로만 다루고 음주를 미화하는 연출은 하지 않는다.

## 3. 시대 배경
- 1막 기준: 정조 즉위 무렵 1776년, 한양 돈의문(서대문) 밖. 지식 베이스 E12(조선 후기)를 쓴다.
- 시간 흐름: 게임 속 1계절 = 실제 플레이 며칠. 막마다 몇 년씩 흐르며 신해통공(1791), 화성 축조(1794), 을묘원행(1795) 같은 사건이 소문과 손님으로 들어온다.
- 고증 원칙: 음식·도구·의복·화폐(상평통보)·장시 주기는 기록 기반. 손님과 사연은 각색이며 화면에서 구분 표시한다.

## 4. 코어 루프
**하루(실제 3~8분)**
1. 아침 장보기: 시전·난전에서 재료를 산다. 계절·흉년·사건에 따라 값이 바뀐다.
2. 장사: 손님이 들어와 주문 → 요리(간단한 탭·순서 미니게임) → 상을 낸다. 손님 취향을 맞히면 인정·단골도가 오른다.
3. 저녁 평상 이야기: 단골 손님 한 명과 짧은 대화(선택지 2~3개). 사연이 한 걸음씩 진행된다.
4. 밤 정리: 매상 정산, 소문 한 줄(그해 사건), 내일 준비.

**중기(일주일~한 달)**
- 단골 사연 완결, 메뉴 개발(레시피 조합으로 새 음식 해금), 주막 확장(방·마당·평상·장독대), 마을 평판 상승으로 새 손님층 등장.

**장기(막 단위)**
- 막 하나 = 몇 년. 막이 끝나면 손님들의 인생이 어떻게 흘렀는지 ‘주막 일지’로 정리된다.

## 5. 손님과 사연
| 구분 | MVP 수량 | 내용 |
|---|---|---|
| 일반 손님 유형 | 20종 | 보부상, 과거 보러 온 선비, 장꾼, 나인, 포졸, 승려, 짐꾼, 기생 악공, 역관 등 |
| 사연 손님(단골) | 12명 | 1인당 에피소드 6~8개. 예: 세 번째 과거에 떨어진 선비, 화성 공사에 간 남편을 기다리는 아낙, 서얼이라 벼슬길이 막힌 젊은이 |
| 실존 인물 | 소수, 손님으로 잠깐 등장 | 정책상 실명 허용 범위(1945년 이전 사망 인물)만. 대사는 각색 표시 |
| 소문 | 40개 | 지식 베이스 기록 사건(확실 등급)에서 뽑아 손님 대사로 |

- 민감 소재(천주교 박해, 노비, 기근)는 사연으로 다루되 선택지로 가해·피해를 고르게 하지 않는다.

## 6. 무료와 인앱결제 구조
원칙: **1막 전체를 무료로 끝까지 즐길 수 있다. 결제는 ‘더 많은 이야기’와 ‘꾸미기’를 산다. 확률형 아이템은 쓰지 않는다.**

| 상품 | 내용 | 가격(가정) | 성격 |
|---|---|---|---|
| 이야기 막 해금 | 2막(1786~1795), 3막(1796~1810) 등. 새 손님·사연·메뉴·사건 | 막당 3,900~5,900원 | 핵심 수익 |
| 전체 이용권 | 출시된 모든 막 + 이후 막 할인 | 12,000~15,000원 | 핵심 수익 |
| 주막 꾸미기 세트 | 계절 장식, 기와·현판, 평상, 소품 묶음 | 1,200~3,900원 | 보조 수익 |
| 주인 의상 | 시대 복식(신분·계절별) | 1,200~2,500원 | 보조 수익 |
| 단골 후원 패키지 | 응원 성격의 묶음 + 감사 엽서 | 2,500~9,900원 | 팬 수익 |
| 편의 | 자동 장보기, 하루 빨리 넘기기 | 2,500원(영구) | 소량 |

- 광고: 기본은 없음. 넣는다면 “오늘 매상 2배” 같은 선택형 보상 광고 하나만(광고 SDK는 서버 비용 없음).
- 하지 않는 것: 에너지·하트 대기 강요, 확률형 뽑기, 기간 한정 압박 판매, 시즌 패스(라이브 운영 필요).
- 국내 확률형 아이템 표시 의무(2024년 시행)는 뽑기를 안 쓰므로 해당 없음으로 설계.

## 7. 운영비 원칙 (적자 방지)
| 항목 | 방식 | 비용 |
|---|---|---|
| 서버 | 없음. 오프라인 싱글 플레이 | 0 |
| 저장 | 기기 저장 + 플랫폼 클라우드 저장(Google Play 게임즈·iCloud) | 0 |
| 결제 | 스토어 인앱결제만. 영수증 검증은 스토어 API 또는 초소형 서버리스(검증 필요) | 수수료 15~30% |
| 콘텐츠 갱신 | 막 단위 유료 업데이트만. 라이브 이벤트 없음 | 제작 시 1회 |
| 고객 지원 | 자주 묻는 질문 + 이메일, 환불은 스토어 정책 | 소량 |
| 분석 | 무료 분석 도구(개인정보 최소 수집) | 0~소액 |

## 8. MVP 범위 (1막 무료 + 2막 유료로 출시)
| 항목 | 수량 |
|---|---|
| 막 | 1막(무료) + 2막(유료) |
| 사연 손님 | 12명(1막 6 + 2막 6) |
| 일반 손님 | 20종 |
| 메뉴 | 30종(국밥, 국수, 전, 막걸리, 떡 등) |
| 주막 확장 단계 | 5단계 |
| 꾸미기·의상 | 60점 |
| 소문 | 40개 |
| 배경 | 주막 1곳(계절·시간대 4종) + 장터·마을 길 3곳 |
- 제작: 1인 PM + 개발 1~2 + 아트(AI 보조 제작·사람 검수) + 고증 감수 1회. 기간 가정 6~8개월(검증 필요).

## 9. 검증 지표 (출시 첫 달, 가설)
- 1막 완주율 30% 이상
- D7 재방문율 15% 이상
- 2막 구매 전환율: 1막 완주자의 10% 이상, 전체 설치자의 1~3%
- 리뷰 평점 4.5 이상

## 10. 위험
| 위험 | 대응 |
|---|---|
| 아늑한 운영 장르는 경쟁이 많고 무료 게임의 결제 전환율이 낮다(일반적으로 몇 %) | 조선이라는 무대와 사연의 질로 차별화. 소프트 런칭으로 전환율 먼저 확인 |
| 무료 게임은 노출·마케팅 비용이 든다 | 한류 커뮤니티·숏폼(손님 사연 영상)·한국어 학습 커뮤니티 위주 무료 유입 |
| 막 단위 판매는 다음 막을 계속 만들어야 한다 | 막을 미리 2개 만들어 두고 출시, 판매 확인 후 다음 막 제작 |
| 고증 오류 | 1~2막 범위의 음식·도구·사건만 원문 대조 + 전문가 1회 감수 |
| 술·기생 등 소재 | 등급 기준에 맞춘 표현 가이드 |
