# 검토: 12개국 전통 식당 × 캐주얼 요리 게임 × 역사 이벤트 (2026-11-22)

오너 안: 조선·일본·중국·미국·프랑스·영국·이집트·인도·브라질·아르헨티나·스페인·러시아 중 선택 → 그 나라 전통 식당에서 캐주얼 요리 게임 → 랜덤 역사 특수 이벤트. 질문: 유입과 결제 전환을 모두 높일 수 있나.

## 판정 (세 관점 일치): 12개국 동시안은 비추천, 결합·축소안 추천
| 항목 | 판정 | 근거 |
|---|---|---|
| 유입 | 비슷~낮아짐 | ‘요리+세계여행’은 Cooking Fever(누적 4.5억 다운로드)·Tasty Travels 등이 점유. 한국사 차별점이 1/12로 희석. 12개국 현지화·고증 비용 12배 |
| 결제 전환 | 낮아짐 | 장르 전환은 소모성 재화 충동 구매에서 나오는데 서버 없으면 재화 경제가 취약. 나라 해금형 판매와 장르가 어긋남. 랜덤 역사 팝업은 결제 동기가 아님 |
| 운영비 조건 | 충돌 | 장르가 라이브 이벤트·레벨 추가·밸런스 조정에 의존. 이용자는 40스테이지를 며칠 만에 소진 |

- 시장 수치: 시간 관리 장르 2025년 매출 1.35억 달러(전년 −12%), 다운로드당 약 0.27달러. 캐주얼 CPI iOS 1.41달러·Android 0.14달러
- ‘테이스트 트래블’ 동명 게임 없음. 가장 가까운 것은 Century Games의 「Tasty Travels: Merge Game」(머지 장르)

## 결합·축소안
1. 본편 「한양 주막」(조선 18세기 후반): 평소 아늑한 운영 + 장날·잔칫날만 타임 매니지먼트 ‘러시 스테이지’
2. 여행 확장 팩(유료): 조선 사람이 실제로 간 곳 — 통신사를 따라간 에도 일본, 연행사를 따라간 청 베이징. 역사 이벤트는 사절단 접대 같은 평시 교류
3. 서구·기타 국가는 판매 데이터 확인 뒤 ‘같은 시대 다른 식당’으로 1~2곳씩(위험 낮은 프랑스 비스트로·현대 카이로 등). 러시아는 제외
- 역사 이벤트 원칙: 완전 랜덤 대신 10스테이지마다 ‘그날의 손님’. 전쟁·혁명은 점수 효과 없이 ‘그날의 소문’ 카드로만. 가해·피해 선택지 금지
- 수익: 첫 나라 무료 + 확장 팩(비소모성, 서버 불필요) + 광고 보상 + 광고 제거. 소모성 재화 비중 낮게
- 제작량: 본편 + 확장 2 + 엔진 약 11~12인월, 서버 0
