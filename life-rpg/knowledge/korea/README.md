# 한국사 지식 베이스 (다시, 한 생)

인생 롤플레잉 게임의 시대 팩·시나리오·인물 생성이 참조하는 한국사 데이터다. 게임 개발 산출물이 아니라 **학습(참조) 자료**이며, 사람과 에이전트가 함께 검수한다.

## 범위

| 항목 | 기준 |
|---|---|
| 시험 범위 | 한국사(한국사능력검정시험 심화·고교 한국사 교과 수준)의 시대 구분과 핵심 개념 |
| 지역 | 현 대한민국 영토 + 고조선·고구려·발해의 옛 영토(한반도 북부·만주 일대) |
| 시대 | 기원전 1000년 ~ 서기 2026년. 서기 0년은 없으므로 **3,026개 연도** |
| 연도별 사건 | 연도마다 3개 이상. 아래 ‘사건 종류’로 기록과 추정을 구분 |

## 파일

| 파일 | 내용 |
|---|---|
| `policy.md` | 실존 인물 이름 처리, 기록·각색 구분, 검수 규칙 |
| `eras.json` | 18개 시대별 정세·핵심 개념·사람들의 성향·남녀노소 의복·고을/마을 모습·이름 짓는 법·생활 사건 풀·그림 프롬프트 키워드 |
| `rulers.csv` | 나라별 왕·정부 시기(재위 연도). 연도별 ‘정세’ 항목의 근거 |
| `events/*.csv` | 시대별 기록 사건(사료·연구로 연도를 특정할 수 있는 사건) |
| `yearly.csv` | **생성 결과물.** 3,026개 연도 각각에 사건 3개 이상 |
| `coverage.md` | **생성 결과물.** 시대별 기록 사건 비율과 검수 현황 |
| `tools/build_yearly.py` | 위 데이터로 `yearly.csv`, `coverage.md`를 다시 만드는 스크립트 |

데이터를 고친 뒤에는 다음을 실행한다.

```bash
python3 life-rpg/knowledge/korea/tools/build_yearly.py
```

## 사건 종류 (yearly.csv의 `kind`)

| kind | 뜻 | 게임에서의 표시 |
|---|---|---|
| 기록 | 사료·연구로 그해에 일어났다고 볼 수 있는 사건 | 역사 노트 · 기록 |
| 정세 | 그해 각 나라의 왕·정부와 재위 연도 | 화면 상단 연호/정세 |
| 생활상 | 그해의 기록이 없거나 적을 때, 그 시대에 흔히 있던 일 | 역사 노트 · 각색(시대 생활상) |

기원전 1000년부터 기원전 4세기까지는 한반도에 연도 단위 기록이 거의 없다. 이 구간의 연도별 사건은 대부분 `정세`와 `생활상`이며, 사실처럼 표시하지 않는다.

## 신뢰도 (`confidence`)

- **확실**: 사료와 학계 통설이 일치
- **통설**: 대체로 받아들여지나 세부 연도에 이견이 있음
- **전승**: 『삼국사기』 초기 기록 등 건국·초기 왕계 전승
- **추정**: 고고학 자료로 시기를 어림한 것(연도는 대표값)
- **검증필요**: 작성자가 확신하지 못해 원문 대조가 필요한 항목

## 현재 상태

초안(작성자 1인, 기억 기반). 사료 원문 대조와 독립 검수 전이다. `coverage.md`의 ‘검증필요’ 항목부터 Historical Researcher가 확인한다.
