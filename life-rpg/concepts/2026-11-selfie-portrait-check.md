- 확인: SDK `openCamera`(촬영)와 `fetchAlbumPhotos`(앨범)는 별도 API·별도 권한 → 촬영만 받는 설계 가능(추정)
- 확인: ‘AI 사진관’(사진→스튜디오 사진) 미니앱 입점 사례 있음. 토스 AI 안전성 검수 강화 보도
- 확인: 광고 정책은 게임·비게임 동일. 인앱결제 수수료 무료는 2026-02-28까지, 이후 요율 미확인
- 미확인: 전면 카메라 기본값·갤러리 버튼 차단, 얼굴·AI 심사 기준, 비게임 소모성 결제, 미니앱 단위 틴즈 차단, 성인 여부 조회, 이야기 기능의 게임물 분류

## 3. 개인정보·법 — 조건부 진행 가능
- 얼굴 사진은 기본적으로 일반 개인정보. 다만 얼굴 유지 API의 내부 임베딩이 민감정보 처리인지 해석이 갈림 → 민감정보 별도 동의까지 받는 것이 안전
- 해외 API: 국외 이전 별도 동의 권장(위탁 공개로 갈음 가능 여부 불확실)
- 만 14세 미만 차단 권장. 14세 이상 청소년은 결제 취소권·따돌림 악용 위험
- AI 기본법(2026-01-22 시행): API 이용 사업자는 생성형 AI 사전 고지 + 결과물 표시. 저장·공유되는 결과물에는 결과물 자체에 표시(보이는 표기 + 메타데이터). 계도기간 종료일 미확인, 11월 법 보완 방침 보도
- 성폭력처벌법(2024-10 개정): 직접 위험은 낮으나 자유 프롬프트 금지·안전 필터·결과물 서버 미보관 필요
- 퍼블리시티권: 공개 갤러리·마케팅 사용·연예인 프리셋 금지. 타인 사진에 비하적 신분 텍스트 주의
