## 1. 한 줄 정의와 목표

> 사무실 한 층에서 **누르고 있으면 땡땡이, 떼면 일하는 척**하는 원터치 눈치 게임. 1판 = 하루 근무(09:00→18:00), 60~90초.

| 밸런스 목표 | 값 | 측정 정의 |
|---|---|---|
| 1판 길이 | 60~90초 | 인트로 시작~결과 화면 진입. 튜토리얼 날(1~5일차)은 50~75초 허용 |
| 초반 성공률(1~10일차) | 70~80% | **성공 = 칼퇴(★2 이상)**. 캐주얼 봇(§12) 기준 |
| 초반 적발률(1~10일차) | ≤ 10% | 의심 100% 엔딩 비율 |
| CEO 순시 생존율 | 40~60% | **생존 = '눈도장' 획득**(순시 중 의심 증가 < 0.15 그리고 인사 QTE 성공). CEO 순시가 직접 원인인 적발은 ≤ 20% |
| 전조(tell) | ≥ 0.4초 | 모든 상사·NPC 시선 시작 전. 시각+청각 동시 |
| 페이크 확률 상한 | 팀장 0.30, CEO 재확인 0.35, **전역 상한 0.35** | 연속 페이크 금지 |

## 2. 조작 (D-001)

| 입력 | 정의 | 의미 |
|---|---|---|
| 홀드 | 누르고 있음 | 땡땡이(딴짓·이벤트 진행). 상사가 보면 의심 상승 |
| 떼기 | 손을 뗀 상태 | 즉시 타이핑 자세 = 안전. 업무 구간이면 업무 게이지 상승 |
| 탭 | 0.25초 이하로 눌렀다 뗌 | 간식 먹기, 게이트 태그, 공범 수락, 간식 나눠 주기, CEO 인사 |

- 화면 어디를 눌러도 같은 입력입니다(버튼 위치 학습 불필요).
- 이동이 필요한 이벤트(화장실·퇴근)는 **홀드 = 앞으로 걷기, 떼기 = 멈춤**. 좌우 1축(뒤로 가기는 자동 복귀 구간에서만).
- 📐 입력 유예 0.12초: 시선이 시작된 뒤 0.12초 안에는 홀드해도 의심이 오르지 않습니다. 모바일 터치 지연(50~100ms)과 손 떼는 동작 시간을 흡수해 "분명 뗐는데 걸렸다"는 억울함을 없앱니다.

## 3. 핵심 루프

```
출근(2초) → [업무 구간 ↔ 이벤트] × N → 몰래 퇴근(피날레, 경비팀 게이트) → 정산(별·월급·도감) → 다음 날 / 승진
              └ 그 위에 상사 AI · 순찰 · CEO 순시 · NPC 개입이 겹쳐 돌아감
```

### 3-1. 하루 구조 (슬롯)
- 하루는 `slots` 배열: `work(초)` → `event` → `work` → `event` … → `work` → `leave`.
- 일반 이벤트 수(퇴근 제외): 인턴 1~2, 사원 3, 대리 3→4, 과장 이상 4. **CEO 순시가 있는 날은 1개 줄임**(순시가 약 11초를 쓰므로 90초 상한 유지).
- 게임 시계: 09:00 → 17:52를 피날레 전 슬롯 진행률에 비례해 선형 표시. 퇴근 이벤트는 17:52부터 실제 1초 = 게임 1분.
- 📐 1판 시간 예산: `2 + Σ업무구간 + Σ이벤트 예상시간`. 사원 = 2 + 4×7.5 + 3×(7~11) + 15 ≈ 69~73초. 과장 = 2 + 5×6.5 + 4×(7~11) + 15 ≈ 84~88초.

### 3-2. 업무 구간
- 상사 AI가 돌아가는 기본 상태. 홀드 = 딴짓(웹서핑): **땡땡이 점수 10점/초**. 떼기 = 업무: **업무 게이지 +0.04/초**.
- 긴장 구조: 점수를 벌려면 홀드, 할당량을 채우려면 떼기, 상사가 보면 무조건 떼기.

### 3-3. 이벤트 구간
- 이벤트별 고유 메카닉(§7). 이벤트 중에도 상사 시선은 그대로 적용됩니다(`observable`). 업무 게이지는 오르지 않습니다.
- 이벤트 실패는 하루를 끝내지 않습니다. 의심 가산(0~0.2) + 보상 없음. 단, **퇴근 실패는 야근 엔딩**.

## 4. 게이지 규칙

### 4-1. 의심 게이지 (0~1)
| 규칙 | 값 | 📐 근거 |
|---|---|---|
| 시선 중 홀드 | 상사별 초당 상승: 선배 0.30 / 팀장 0.45 / 임원 콘 0.60 / CEO 0.90 / 인사팀 0.50 | 팀장 시선 1회(1.0~2.0초)를 통째로 버텨도 0.45~0.9 → **한 번의 실수로는 끝나지 않고 2~3번이면 끝남** |
| 동시 시선 | 가장 높은 상승률 하나만 적용(합산 안 함) | 겹침으로 인한 순간 사망 방지, 시뮬 단순화 |
| 자연 감소 | 떼고 있고 아무도 안 볼 때 −0.02/초 | 하루 70초 중 회복 여지 최대 ~0.5. 실수 후 만회 가능 |
| 이벤트 실패 | 이벤트별 즉시 가산 0~0.2 | 실패가 곧장 적발로 이어지지 않게 0.2 이하 |
| 100% 도달 | **적발 엔딩**("○○ 씨, 잠깐 나 좀 볼까?") | 보고서 §3-3 |
| 이어하기 광고 🔶 | 하루 1회, 의심 0.6으로 낮추고 현재 이벤트 재시작 | REQ-006 |
| 연속 적발 보조 | 같은 날 3연속 적발 시 다음 시도 상승률 ×0.85 + 힌트 | 이탈 방지. 무료·무조건 |

### 4-2. 업무 게이지 (0~1)
- 업무 구간에서 떼고 있을 때만 +0.04/초. 이벤트 중에는 변화 없음.
- 할당량: 인턴 0.45(1일차 0.35) / 사원 0.50 / 대리 0.55 / 과장 0.60 / 차장 0.62 / 부장 0.64 / 임원 0.65.
- 📐 업무 구간 총합 대비 필요 '떼기 비율'을 직급 내내 **42~51%**로 유지 → 업무 구간의 절반은 딴짓할 여유. 직급이 오르면 비율이 아니라 상사 패턴이 어려워집니다.

### 4-3. 땡땡이 점수 (점수·리더보드용)
- 업무 구간 홀드 10점/초, 이벤트 성공 보상(150~250점), 화장실 안 홀드 20점/초, CEO 대화 구간 ×2, 눈도장 +300, 18시 전 퇴근 +100.

### 4-4. 하루 결과와 별점
| 결과 | 조건 | 별 |
|---|---|---|
| 적발 | 의심 100% | ★0 |
| 야근 엔딩 | 생존했지만 업무 < 할당량, **또는** 퇴근 이벤트 실패 | ★1 |
| 칼퇴 | 업무 ≥ 할당량 **그리고** 퇴근 성공 | ★2 |
| 완벽 칼퇴 | 칼퇴 + **하루 최고 의심도 < 30%** | ★3 |

- ★3은 '최고치' 기준(최종치는 자연 감소로 너무 쉬워짐).
- 월급(소프트 재화) = `직급 기본급 × [0.3, 0.6, 1.0, 1.3][별] + floor(땡땡이점수/10)`. 결정적 계산, 랜덤 없음.
- 월급 2배 광고 🔶: 결과 화면에서 1회. 게임 내 재화에만 적용(토스포인트 아님).

## 5. 상사 4종과 위계 연쇄 (REQ-004)

공통 상태 머신: `idle(등 돌림) → tell(전조) → look(시선) → return(돌아섬) → idle`
- 페이크: `tell → (시선 없이) 헛기침 → idle`. **연속 페이크 금지**: 페이크 다음 사이클의 전조는 반드시 진짜.
  - 📐 그래서 체감 페이크 비율 ≤ p/(1+p). 팀장 상한 0.30이면 실제 전조 중 페이크 ≤ 23%. "전조 = 떼라"는 신뢰가 깨지지 않는 선.
- 모든 시선은 tell 없이 시작하지 않습니다(상위 상사 퇴장 후 복귀 직후 포함).

### 5-1. 선배 (튜토리얼, 인턴 1~5일차)
| 항목 | 값 |
|---|---|
| 패턴 | 고정 주기: idle 3.0 → tell 1.0 → look 1.2 → return 0.3 (5.5초 주기) |
| 전조 | 머리 위 '…' 말풍선 + "흠" 효과음, 1.0초 |
| 페이크 / 연속 보기 | 없음 |
| 시선 상승률 | 0.30/초 |
| 소품 | 스티커 붙은 머그, 초록 사원증 줄 |
| 📐 | 리듬만 익히면 되는 메트로놈. 1일차 첫 시선은 스크립트(전조 1.2초, 상승률 ×0.5) |

### 5-2. 팀장 (사원~)
| 항목 | 사원 시작 → 끝 | 대리 | 과장 | 차장 이상 |
|---|---|---|---|---|
| idle | 2.5~4.5 → 2.2~4.2 | 2.0~4.0 | 1.8~3.8 | 1.6~3.6 |
| 전조(의자 삐걱 + 등 움찔) | 0.6~0.8 → 0.55~0.8 | 0.5~0.75 | 0.45~0.7 | 0.4~0.65 |
| look | 1.0~1.6 → 1.0~1.8 | 1.0~2.0 | 1.2~2.0 | 1.2~2.0 |
| 페이크(헛기침) | 0.10 → 0.15 | 0.15 → 0.22 | 0.22 → 0.28 | 0.28 → **0.30(상한)** |
| 연속 두 번 보기 | 0 → 0.10 | 0.12 → 0.18 | 0.18 → 0.22 | 0.22 → **0.25(상한)** |
| 통화(기회) | 사이클당 0.20 → 0.18 | 0.15 | 0.12 | 0.10 |

- 연속 보기: look 종료 → 0.5초 등 돌림 → 두 번째 전조 0.4초 → look 0.8~1.2초.
- 통화 중: 수화기 아이콘, 3~5초 시선 OFF. 끝나기 0.5초 전 "네, 들어가세요~" 전조.
- 차장부터 **옆 팀 팀장**(같은 데이터, 2번째 인스턴스, 다른 책상) 추가.

### 5-3. 임원(본부장, 대리~)
| 항목 | 값 |
|---|---|
| 출현 | 하루 1회(대리 초반) → 1~2회(대리 후반·과장) → 2회(부장~). 순찰 간 최소 12초 |
| 전조 | **구두 발소리 크레셴도 + 화면 끝 그림자, 1.5초** |
| 이동 | 복도 14타일을 1.6타일/초(과장 후반 1.8, 부장 1.9)로 통과 ≈ 8~9초 |
| 시선 | 진행 방향으로 콘(길이 4타일, 50°). 콘이 내 책상에 닿기 **0.5초 전 책상 테두리 깜빡**(전조 보장) |
| 정지 | 확률 0.4→0.65로 한 번 멈춰 1.5~2.5초 좌우 둘러봄. 방향 바꾸기 전 고개 돌림 0.5초 |
| 기회 | 10% 확률로 커피를 흘림 → 2초 시선 OFF (허당 연출) |
| 시선 상승률 | 0.60/초 |

### 5-4. CEO(대표님, 과장~)
| 단계 | 길이 | 규칙 |
|---|---|---|
| ① 전조 | 1.0초(직급 무관 고정) | **엘리베이터 '띵' + BGM 정지 + 모든 NPC 동시에 고개 듦** |
| ② 얼음 | 3~5초 (**최대 5초**) | 층 전체 정지. 홀드 시작 순간 **+0.20**, 홀드 유지 0.9/초. 떼면 업무 게이지는 정상 상승("진짜 일하는 척") |
| ②-1 인사 QTE | 얼음 안에서 | 대표님이 내 자리 앞에서 '?'(0.6~1.2초 무작위) → '!' 후 **0.6초(차장~ 0.5초) 안에 0.4초 이하로 짧게 톡**. 너무 빠름 +0.10 / 놓침 +0.15 / 길게 누름 +0.20 |
| ③ 재확인 페이크 | 35% (과장 초반 30%) | 팀장 쪽으로 가다 멈추고 어깨 들썩(0.5초 전조) → 1.0초 뒤돌아봄(0.9/초) |
| ④ 대화(기회) | 4.0초 | 대표님이 팀장과 대화 → **팀장·임원 시선 OFF**, 땡땡이 점수 ×2 |
| ⑤ 퇴장 | 1.5초 | '띵' + BGM 복귀, 하위 상사 1.0초 후 복귀 |

- 출현: 과장 이상 **수요일 정기 순시**(28·33·38일차…) + 그 외 날 8%(임원 직급 12%) 🔶(확률형 '콘텐츠'이지 보상 아님).
- 생존(눈도장) = ①~⑤ 동안 의심 증가 < 0.15 + QTE 성공 → +300점, 도감 '대표님 눈도장'.
- CEO 순시 패스 광고 🔶: 순시를 건너뜀(눈도장 보너스 없음). 보고서 §7 리스크 대응.
- 📐 생존율 추정: QTE 성공 ~75% × (1 − 페이크 0.35 × 낚임 0.45) × 얼음 중 조급 홀드 방지 ~0.9 ≈ **0.57**. 목표 40~60% 안. 🧪 QA가 봇으로 실측 후 `fake.prob`, `greetingQte.windowSec`로 조정.

### 5-5. 위계 연쇄 규칙
| # | 규칙 | 효과 |
|---|---|---|
| H1 | 임원이 화면에 들어오면 팀장은 일어나 인사(`greeting`) → **팀장 시선 OFF** | 위기 = 기회. 콘만 피하면 팀장 걱정 없음 |
| H2 | 임원 퇴장 후 팀장은 1.0초 뒤 착석, 다음 시선은 반드시 전조부터 | 복귀 즉시 시선 금지 |
| H3 | CEO 전조~퇴장 동안 팀장·임원·선배는 `frozen`(시선 OFF). 시선은 CEO만 | |
| H4 | CEO 얼음 중 NPC(고자질·공범·인사팀) 모두 정지·타이머 정지 | |

## 6. NPC 4종 (REQ-005)

### 6-1. 경비팀 (관문)
- 퇴근 이벤트의 **게이트 단계 전담**. 사원증 태그: 막대가 1.2초 주기로 왕복, 초록 칸(주기의 22% → 과장 16% → 부장 14%)에서 탭. 실패 "삐빅" +0.10, 최대 3회. 3회 실패 = 퇴근 실패(야근 엔딩).
- 18:00 이전 도착 시 "벌써 퇴근하세요?" → 1.5초 지연(그동안 상사 시선 계속). 대신 **18시 전 탈출 +100점**. 빠를수록 점수, 대신 노출 1.5초.
- 톤: 유능하고 친절한 프로("오늘 하루도 고생 많으셨어요~"). 놀림 대상 금지.
- 야근 모드 손전등 순찰은 backlog(MVP 밖).

### 6-2. 고자질 동료 → 표시명 '정의로운 동료' (방해)
- 업무 구간에서 **홀드 중 1초마다 4%**(과장 6%) 판정, 하루 1회(대리 후반~ 2회), 하루 시작 10초 이후, 쿨다운 15초.
- 전조: "어? 저거…" + 일어남 0.6초 → 팀장 자리로 4.0초(과장 3.2초) 걸어감(경로 표시).
- 대응: ① **1.5초 연속 떼기** → "내가 잘못 봤나?" 복귀 / ② **탭**으로 간식 나눠 주기(간식 1개 소모) → 즉시 취소.
- 도착 시: 의심 +0.15, 팀장 강제 시선(전조 0.5초 → 2.5초 look).
- 간식 재고: 하루 시작 1개, 간식 이벤트 성공 +1, 최대 3. 결정적(랜덤 획득 없음).
- 톤: 악당이 아니라 눈치 없는 정의파. 간식 받으면 금방 풀림. 이름에서 '고자질'은 내부 ID(`snitch`)로만 쓰고 화면엔 '정의로운 동료'.

### 6-3. 공범 동료 (조력)
- 커피·간식 이벤트 시작 전 60% 확률로 제안 말풍선 2.5초("커피 같이 가실래요?"), **탭 = 수락**, 무시 = 거절. 하루 1회. 7일차 첫 커피는 강제 제안.
- 수락 효과: 보상 ×2 / 진행 요구량 증가(커피 2잔, 간식 한 입 수 ×1.5) / 의심 상승 ×1.25 / **망보기: 상사 전조보다 0.3초 먼저 헛기침**(실질 경고 시간 +0.3초).
- 📐 위험(노출 시간 약 +60%, 상승률 +25%)과 보상(×2, 조기 경고)을 맞바꾸는 선택지. 결정적 효과라 확률형 보상 아님.

### 6-4. 인사팀 (점검)
- 10일차부터. 하루 확률 40%(사원) → 60%(대리) → 70%(과장~), 최대 1회, 하루 시작 12초 이후. CEO 순시·퇴근 중에는 없음.
- 전조: 복도 문 열림 + 클립보드 1.0초 → 2.0초 걸어와 **5.0초 근태 점검**.
- 점검 중: 자리에 있어야 함. 홀드하면 0.5/초. 자리를 비웠으면(커피·화장실 중) **"자리로 복귀! 4초"** → 홀드로 귀환(속도 ×1.5). 시간 초과 시 +0.25 + "자리 비움으로 기록해 둘게요~".
- 10일차는 화장실 안에서 강제 발생(튜토리얼).
- 톤: 깔끔한 프로. 징계·위협 묘사 금지.

## 7. MVP 이벤트 6종 상세 (REQ-003)

공통: 시선 중 홀드 = 해당 상사 상승률 × 이벤트 배수. 성공 보상은 땡땡이 점수. 수치는 인턴 기본값, 직급 변화는 `events.json` `rankScaling`.

### 7-1. 몰래 커피 (`coffee`, 탕비실, 홀드)
| 항목 | 값 |
|---|---|
| 진행 | 홀드 = 따르기(수위 +0.45/초). 떼면 멈춤 |
| 성공 | **목표 띠 [0.75, 0.92] 안에서 뗌** |
| 실패 | 수위 1.0 도달 = 넘침(+0.15, "앗, 넘친다! …아무 일도 없었던 척") |
| 시간 제한 | 10초. 초과 시 미완료(벌점 없음, 보상 없음) |
| 직급 | 띠가 좁아지고(과장 [0.80, 0.90]) 속도 0.5~0.6 |
| 공범 | 2잔 |
| 📐 | 띠 폭 0.17 ÷ 0.45 = **0.38초 창**(과장 0.2초). 시선 때문에 끊어 따르면 다시 눌렀을 때 남은 거리가 짧아 정밀도 요구 증가 → 상사 패턴과 자연스럽게 얽힘 |

|---|---|
| 진행 | 홀드 = 걷기 2.0타일/초, 편도 6타일. 떼면 멈춤 |

| 노출 | 걷다 걸림 ×1.2 / 은신처 밖에서 멈춘 채 걸림 ×0.5 |
| 화장실 안 | 3.0초 휴식(시선 없음), 홀드하면 +20점/초 |

| 실패 / 시간 | 16초 초과 = "너무 오래 자리를 비웠다…" +0.2 |
| 📐 | 왕복 최소 6초 + 휴식 3초 = 9초, 은신 대기 포함 예상 11초. 팀장 한 사이클(약 4~6초)에 1~2번 시선 → 은신 1~2회가 정상 플레이 |

### 7-3. 몰래 낮잠 (`nap`, 자리, 홀드)

## 10. 실패 리액션과 도감

- 적발 시 2.0초 컷인: 잡은 주체(상사/NPC/이벤트)의 리액션 대사 + 정지 포즈. 그다음 결과 화면.
- 리액션은 **리액션 도감**에 수집(처음 본 `react.*` 키 해금). 실패가 콘텐츠가 됨.
- 도감 3종: 상사(처음 등장 시 해금), 동료(처음 등장 시), 리액션(처음 발생 시). + 업적성 항목 '대표님 눈도장'.
- 해금은 모두 행동에 따른 결정적 해금. 뽑기·랜덤 지급 없음(D-004).

| 주체 | 대표 대사 (전체는 strings `react.*`) |
|---|---|
| 선배 | "어… 그거 나도 인턴 때 해 봤어. 근데 지금은 일하자?" |
| 팀장 | "{name} 씨, 잠깐 나 좀 볼까?" |
| 임원 | "자네 이름이… 아, 기억해 두지." |
| CEO | "자네, 열정이 넘치는구먼. 내일 아침 회의에 들어와요." |
| 경비팀 | "사원증이… 거꾸로 꽂혀 있네요. 천천히 다시 찍어 보세요!" |
| 정의로운 동료 | "팀장님~ 저기 {name} 씨가 좀…" |
| 인사팀 | "자리 비움으로 기록해 둘게요~" |
| 커피 / 낮잠 / 간식 | "앗, 넘친다!" / "쿵! …회의 자료를 아주 가까이서 보고 있었습니다." / "바스락!!" |

대사 원칙: 폭언·해고 협박·비하 없음. "들켰다"의 민망함으로 웃기기. 상사도 허당.

## 11. 접근성·공정성 규칙
- 전조는 항상 **시각 + 청각**(소리 끈 플레이어 대응). CEO의 BGM 정지도 'NPC 고개 듦'과 함께.
- 전조 최소 0.4초, 입력 유예 0.12초, 연속 페이크 금지.
- 같은 날 = 같은 시드. 재도전 시 같은 패턴 → 학습 가능.
- 진동(설정): 전조 시작 시 짧은 진동 옵션.

## 12. 🧪 QA 시뮬레이션 사양 (T-114용)

봇 3종(파라미터는 QA가 조정 가능):

| 봇 | 전조 반응 시간 | 탐욕(안전할 때 홀드 비율) | 페이크 후 행동 | 리듬·타이밍 오차 |
|---|---|---|---|---|
| 신중 | N(0.30, 0.08)초 | 0.5 | 항상 뗌 | σ 0.06초 |
| **캐주얼(기준)** | N(0.38, 0.10)초 | 0.65 | 20% 확률로 무시하고 계속 홀드 | σ 0.10초 |
| 욕심 | N(0.42, 0.12)초 | 0.85 | 40% 무시 | σ 0.12초 |

검증 항목과 합격선(캐주얼 봇, 시드별 1,000회):
1. 일차별 1판 길이 평균 60~90초(1~5일차 50~75초).
2. 1~10일차 칼퇴(★2+) 70~80%, 적발 ≤ 10%.
3. CEO 순시 눈도장 40~60%, CEO 원인 적발 ≤ 20%.
4. 모든 시선 전 전조 ≥ 0.4초(로그로 전수 검사), 연속 페이크 0건.
5. 직급별 승진 기준 도달까지 평균 재도전 ≤ 직급 일수의 30%.
6. 이벤트별 성공률: 커피·화장실·쇼핑 80~90%(인턴), 간식·낮잠 75~85%, 퇴근 85~95%.

조정 손잡이 우선순위: ① 팀장 `idleSec`·`fake.prob` ② 이벤트 `timeLimitSec`·목표 띠 ③ `workQuota` ④ 의심 상승률. 전조 최소값·페이크 상한은 낮추지 않습니다.
