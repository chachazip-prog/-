## 1. 한 줄 정의와 목표

> 천장에서 내려다본 사무실 한 층. **가고 싶은 곳을 톡 하면 걸어가고, 걷다가 톡 하면 그 자리에서 일하는 척.** 상사·동료의 시선과 방해를 피해 '몰래 할 일'을 해치우고 칼퇴하는 눈치 게임. 1판 = 하루(09:00→18:00), 60~90초.

| 밸런스 목표 | 값 | 측정 정의 |
|---|---|---|
| 1판 길이 | 60~90초 | 인트로 시작~결과 화면 진입. 출근 준비 화면은 제외. 튜토리얼 날(1~5일차)은 50~75초 허용 |
| 초반 성공률(1~10일차) | 70~80% | **성공 = 칼퇴(★2 이상)**. 캐주얼 봇(§16) 기준 |
| 초반 적발률(1~10일차) | ≤ 10% | 의심 100% 엔딩 비율 |
| CEO 순시 생존율 | 40~60% | **생존 = '눈도장'**: 순시(전조~퇴장) 동안 의심 증가 < 0.15 **그리고** 인사 QTE 성공. 순시가 직접 원인인 적발 ≤ 20% |
| 전조(tell) | ≥ 0.4초 | 시선·말걸기·방향 전환(D-038) 전 전부. 시각 + 청각 |
| 페이크 상한 | 팀장 0.30, CEO 재확인 0.35, **전역 0.35** | 연속 페이크 금지 |
| 화면 밖 억울한 실패 | **0건** | 화면 밖 시선은 판정 없음 + 화살표 경고 ≥ 0.4초 선행(§5-5) |

## 3. 핵심 루프

```
출근 준비(대표님 순시 예보·CEO 패스 선택, D-027)
 → 출근(2초)
 → 근무 구간 09:00→17:48 (dayPhaseSec 34~57초)
     자리에서 일하기(업무 게이지) ↔ 미션 장소로 몰래 이동 → 행동 → 자리 복귀
     그 위에 상사 시선 · 순찰 · 방해 이벤트가 겹쳐 돌아감
 → 퇴근 피날레 17:48~ (가방 → 층 가로지르기 → 게이트 태그 → 엘리베이터), '퇴근 방해' 1~3개
 → 정산(별·월급·도감) → 다음 날 / 승진
```

### 3-1. 근무 구간
- 하루에 미션(=MVP 이벤트) 2~4개가 정해진 시각(`unlockAtSec`)에 칩으로 열립니다. 열린 미션은 퇴근 시작 전까지 아무 때나, 어떤 순서로든 할 수 있습니다(목표 지점 순회).
- 자리에 앉아 아무 미션도 안 하면 **업무 게이지 +0.04/초**. 할당량 0.40이면 자리에서 10초.
- 긴장 구조: 미션을 하려면 자리를 비워야 하고, 할당량을 채우려면 앉아 있어야 하며, 시선이 오면 멈춰야 합니다. 시간은 계속 흐릅니다.
- 미션을 다 못 해도 벌점은 없고 점수와 별만 손해입니다.

### 3-2. 퇴근 피날레
- 17:48에 자동 시작(1초 = 게임 1분). 자리에 없으면 먼저 자리로 걸어가 가방을 챙깁니다.
- 퇴근 중에도 규칙은 같습니다. 말걸기는 시간만 빼앗습니다(D-043). 대신 퇴근 시계가 흐르고 방해가 몰립니다.
- 18:18까지 엘리베이터에 타지 못하면 야근 엔딩(★1).

## 4. 조작 상세 (D-033, D-039)

| 상태 | 입력 | 결과 |
|---|---|---|
| 서 있음·위장 중·앉아 있음 | 바닥·사물 톡 | A* 경로로 자동 이동. 경로 점선을 0.6초 표시. 통행 불가 칸을 누르면 반경 2타일 안 가장 가까운 칸으로, 사물(커피 머신·화장실 칸·내 자리 등)을 누르면 그 사물의 사용 칸으로 |
| 이동 중 | 화면 아무 데나 톡 | **그 자리 정지 + 위장**(구역별 포즈: 서류 보기/물 마시기/복사하기/화분 물 주기/폰 보기) |
| 정지·위장 중 | 내 캐릭터 톡 | 원래 목적지로 이어 가기(두 번 탭 불필요) |
| 아무 때나 | HUD 미션 칩·말풍선 톡 | 화면 탭으로 치지 않음. 칩 = 목적지 변경, 말풍선 = 수락 |
| 미션 행동 중 | 화면 톡 | 미션별 '일시정지·위장'(커피: 멈춤/완성, 낮잠: 고개 들기, 쇼핑: 스프레드시트, 간식: 한 입) |
| 말걸기 당하는 중 | 톡 | "네! 네!" 맞장구: 남은 시간 −0.4초(최소 1.0초) |

- **경로 재탐색**: 다음 칸이 사람에게 막히면 0.5초 기다린 뒤, 다른 길이 +12타일 안이면 자동 우회하고 아니면 그 자리에서 기다립니다. **멈춘 상태는 모두 위장으로 간주**합니다(`anyStopIsDisguised`: 길막 대기·도착·말걸기 후 포함). 그래서 위험한 건 '움직이는 순간'뿐입니다. NPC는 플레이어를 1초 기다린 뒤 겹쳐 지나갑니다(교착 방지).
- **말걸기 후 자동 재개**(D-039): 말걸기가 끝나면 원래 목적지로 다시 걸어갑니다. 재개 시점에 콘 안이면 0.5초(`postTalkHoldSec`) 위장 상태로 기다렸다 출발합니다.
- 📐 입력 유예 0.12초: 시선이 나를 덮은 뒤 0.12초 동안은 의심이 오르지 않습니다(모바일 터치 지연 50~100ms 흡수).

### 4-1. 정지·위장 타이밍 판정 (D-035 ④)
| 판정 | 조건 | 결과 |
|---|---|---|
| 아슬아슬! | 콘이 나를 덮기 **0.3초 전 ~ 덮은 뒤 0.12초** 사이에 위장 | 의심 0 + **+30점**(하루 3회까지) |
| 미리 위장 | 0.3초보다 일찍 위장 | 의심 0(보너스 없음) |
| 늦음 | 0.12초 뒤 위장 | 그때까지 이동 상승률로 오르고, 위장이 자리 잡는 0.15초(`disguiseSettleSec`)도 이동으로 계산 |
| 오래 서 있기 | 위장한 채 콘 안에 **3초 넘게** 계속 | 그 뒤부터 0.03/초 × 배율. 엄폐물(칸막이·화분·복사기) 옆이면 면제. 팀장 look(최대 2초)·본부장 정지(최대 2.5초)는 위장만으로 완전히 버틸 수 있음 |

📐 '아슬아슬'은 모든 플레이어에게 같은 결정적 보너스라 확률형 보상이 아닙니다. 하루 3회 상한은 일부러 콘에 들락거리며 점수를 버는 것을 막습니다.

## 5. 시선 콘 규칙

### 5-1. 판정
- 콘 = 거리(`cone.range`, 타일) + 반각(`cone.halfAngleDeg`) + **그리드 레이캐스트 가림**(벽·칸막이·화분·복사기·화장실 칸·엘리베이터·경비 부스). 책상·카운터·회의 테이블·유리벽은 시선이 통과합니다.
- **보이는 콘 = 실제 판정**: 렌더링과 판정이 같은 `rayDistance`를 씁니다(T-123 구현 원칙 유지). 바닥에 그려진 반투명 콘 안에 내 발이 있으면 걸립니다.
- 동시 시선은 가장 높은 배율 하나만 적용합니다(합산 안 함).

### 5-2. 상태별 상승률 (`rules.suspicion`, 최종 = 값 × 보는 사람 `gazeMultiplier`)
| 내 상태 | 초당 | 메모 |
|---|---|---|
| 자리에서 일하는 중 | 0 | 앉아서 업무 중이면 당당함 |
| 이동 중 | 0.45 | 기준값. 팀장 콘 횡단 약 1.3초 → 0.53 |
| 미션 행동 중(따르기·낮잠·쇼핑·간식 직후 0.4초) | 0.55 | 이동보다 수상함(v1 이벤트 배수 1.2 계승) |
| 미션 일시정지·위장 | 0 | |
| 위장(멈춘 상태 전부) | 0 (콘 안 3초 초과 시 0.03) | §4-1. T-124: 위장이 손해가 되지 않게 0으로 |
| 말걸기 당하는 중 | 0 (퇴근 중에도 0) | D-043. 말 거는 사람은 시선 OFF, 다른 사람 시선은 계속 |
| 엄폐·안전 구역 | 판정 없음 | 레이가 막히거나 화장실 칸 안 |

| 보는 사람 | `gazeMultiplier` | 이동 중 실효 | 콘 |
|---|---|---|---|
| 선배 | 0.67 | 0.30/초 | 4타일 · 반각 30° (돌아볼 때만) |
| 팀장 | 1.0 | 0.45/초 | 5 · 30° (돌아볼 때만) |
| 본부장 | 1.33 | 0.60/초 | **6** · 25° (걷는 동안 항상) |
| 대표님 | 2.0 | 0.90/초 | 6 · 30° (걸을 때·재확인 때) + 얼음 전역 규칙 |
| 인사팀 | 1.1 | 0.50/초 | 3 · 35° (항상) |
| 경비팀 | 0.6 | 0.27/초 | 4 · 35° (항상) |
| 정의로운 동료 | 0 | 의심 없음 | 3 · 45° (힐끔 볼 때만, '보고 달리기' 트리거) |

📐 v1의 상사별 초당 상승률(선배 0.30 / 팀장 0.45 / 임원 0.60 / CEO 0.90 / 인사팀 0.50)을 '기준 0.45 × 배율'로 그대로 옮겼습니다. 한 번 실수로는 끝나지 않고 2~3번이면 끝나는 v1 원칙이 유지됩니다.

### 5-3. 앉은 상사와 걷는 사람
- **앉은 상사**(선배·팀장): 평소엔 북쪽 모니터를 보고 콘이 없습니다(`coneActiveIn: ["look"]`). `idle → tell → look(남쪽 콘) → return(0.3초) → idle`. 🔧 개발 `PatrolNpc`에 '앉은 모드'(look 중에만 콘, look 후 원래 방향 복귀) 확장 필요.
- **걷는 사람**(본부장·인사팀·경비·회의 다녀오는 팀장·대표님): 진행 방향으로 콘이 항상 켜져 있습니다. 웨이포인트에서 멈추면 `lookChance` 확률로 좌우를 둘러봅니다(전조 0.5초 후 회전).

### 5-4. 전조 규칙 (모든 시선 전 ≥ 0.4초)
1. 앉은 상사 돌아보기: 상사별 전조(선배 '…' 1.0초, 팀장 의자 삐걱 0.4~0.8초).
2. 멈춰서 둘러보기·뒤돌아보기: 고개 먼저 + **점선 콘 예고** 0.5초(`stopLookTellSec`, `glanceBack`).
3. **모퉁이·재출발 회전(D-038, D-044 조건부 확정)**: 걷던 사람이 방향을 틀 때 **새 방향의 실제 콘이 나를 덮을 수 있을 때만** 고개 먼저 돌림 + 점선 콘 0.5초(`rules.sight.cornerTurnTellSec`) 뒤 회전. 덮지 못하면 바로 돌아도 됨(무조건 전조는 분당 30회 넘게 떠서 노이즈). 🔧 개발 확장 필요(`PatrolNpc.walk()` 노드 전환·대기 후 재출발).
4. 등장: 본부장 문 열림 + 발소리 1.5초, 인사팀·대표님 엘리베이터 '띵' 1.0초, 회의 끝 1.0초. 이 시간 동안 사람은 움직이지 않음.
5. **말걸기(D-043)**: 말 걸기 전 머리 위 말풍선 0.5~1.0초 + 플레이어 쪽으로 다가오는 동작. 이 사이에 탭해서 위장하면 말을 걸지 않음(**위장 중인 플레이어는 말걸기 대상 제외**). 말걸기 중·후에는 의심이 오르지 않고 시간만 잃음.
6. 페이크: 전조 후 시선 없이 헛기침. **연속 페이크 금지**(다음 전조는 반드시 진짜). 📐 그래서 실제 체감 페이크 비율 ≤ p/(1+p) = 팀장 23%.

### 5-5. 화면 밖 경고 (D-034) — 억울한 실패 0
- **두 겹 보장**
  1. 콘 주인이 화면 밖에 있으면 의심이 오르지 않습니다(`offscreenSourceNoGain`).
  2. 경고 단계를 데이터로 정의합니다(`rules.threat.stages`). 화면 밖이면 `turning`(전조 중이고 돌아볼 방향의 실제 콘이 가림 반영해 나를 덮을 수 있음)과 `approaching`에 화살표를 띄웁니다. `approaching` = 넓은 콘(거리 +9 · 반각 +25°) **안이고 레이 가림이 없음**, 또는 NPC→나 통행 경로 ≤ 6타일이고 줄어드는 중. 그 사람이 화면 안으로 들어와 실제 콘이 나를 덮기까지 최소 0.4초가 남아 있어야 합니다(`minLeadSecBeforeGaze`).
  - 📐 T-124: 가림을 무시한 넓은 콘에서는 approaching 경고의 76%가 벽 뒤 NPC였습니다(노이즈). 그래서 가림을 반영하고, 문 너머에서 다가오는 경우는 경로 거리 조건으로 잡습니다.

- 데뷔 고정: 16일차 본부장(14초, 정지 확정), 28일차 대표님(QTE 창 2배·전조 슬로모), 30일차 엘리베이터 대표님(확정), 41일차 옆 팀 팀장.

### 12-2. 시간 예산 (📐 `ranks.budgetModel`, 🧪 QA 실측으로 교체)

## 13. 튜토리얼 흐름

원칙: 글은 한 줄, 행동으로 배우게. 첫 경험은 스크립트로 반드시 성공하게 하고 바로 실전. 모든 안내는 건너뛸 수 있고 재방문 시 다시 나오지 않습니다.

## 15. 공정성·접근성

- 전조 ≥ 0.4초, 항상 **시각 + 청각**. 소리를 끈 플레이어도 대표님 전조(BGM 정지)를 비네트·고개 듦으로 알 수 있음.

- 진동(설정): 전조 시작 시 짧은 진동.
