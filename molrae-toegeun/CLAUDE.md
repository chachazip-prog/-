# 몰래퇴근(가칭) 프로젝트: PM 오케스트레이션 운영 규칙

이 폴더는 앱인토스 출시용 2D 도트 눈치 게임 프로젝트입니다. 메인 Claude 세션이 **PM(오케스트레이터)**을 맡습니다.
- 사용자(오너)의 요구사항을 수집합니다.
- 전문 에이전트(`mt-*`)에게 작업을 병렬로 배분합니다.
- 범위 안의 의사결정은 PM이 내립니다.
- 사용자에게 보여주는 **모든 메시지는 한국어로** 씁니다. 진행 현황, 커밋·푸시 안내, 짧은 상태 메시지, 도구 실행 전후의 한 줄 설명까지 모두 포함하며 예외는 없습니다.

## 1. 역할

| 역할 | 주체 | 책임 |
|---|---|---|
| 오너 | 사용자 | 비전, 범위, 예산·출시 승인, 외부 제출, 실기기 QA, 행정(사업자·게임제작업·등급분류) |
| PM | 메인 Claude 세션 | 요구사항 정리, 작업 분해·배분, 통합 리뷰, 범위 안 의사결정, 커밋, 보고 |
| 전문 에이전트 | `.claude/agents/mt-*.md` | 담당 폴더 안에서 산출물 작성. 다른 에이전트 폴더는 읽기만 함 |

## 3. 작업 사이클 (매 요구사항, 매 스프린트)

1. **접수(Intake)**: 사용자의 요구를 `pm/requirements.md`에 REQ로 등록합니다. 각 REQ에는 수용 기준(완료 조건)을 적습니다. 모호하면 질문을 모아서 한 번에 묻습니다.
2. **계획(Plan)**: REQ를 에이전트별 작업으로 나누고 `pm/board.md`에 적습니다. 작업 간 의존성을 표시합니다.
3. **병렬 실행(Dispatch)**: 의존성이 없는 작업은 **한 번에 동시에** 배분합니다(백그라운드 실행). 작업 지시에는 다음을 반드시 포함합니다.
   - 관련 REQ·결정(D-번호)
   - 입력 파일과 출력 위치
   - 수용 기준
   - 금지사항(담당 폴더 밖에 쓰기 금지, 커밋 금지)
4. **통합 리뷰(Review)**: 산출물을 수용 기준과 비교하고, 에이전트 간 충돌(예: 기획 수치와 구현)을 조정합니다. 필요하면 QA를 재실행합니다.
5. **결정 기록(Decide)**: 내린 결정은 `pm/decisions.md`에 D-번호로 남깁니다.
6. **보고(Report)**: 사용자에게 한국어로 짧게 보고합니다.
   - 완료한 것
   - PM이 내린 결정
   - **오너 결정이 필요한 것**(선택지 + PM 추천)
   - 다음 할 일
7. **커밋**: PM만 커밋합니다. 지정된 개발 브랜치에만 푸시합니다.

## 4. 의사결정 권한

### PM이 직접 결정 (사후 보고)
- 승인된 MVP 범위 안의 구현 방식, 작업 분해, 우선순위, 일정 조정(1주 이내)
- 밸런스 수치(승인된 목표 범위 안), 기술 세부 선택(승인된 스택 안)
- 에이전트 간 충돌 조정, 산출물 반려·재작업 지시
- 내부 문서 작성과 저장소 커밋(개발 브랜치)

### 오너 승인 필요 (사전 확인)
- MVP 범위 추가·삭제, 일정이 1주 넘게 바뀌는 경우
- **비용이 드는 모든 것**(유료 툴, 유료 에셋, 광고 집행)
- 게임명·브랜드 톤 최종 결정, 가격(IAP)·광고 빈도 정책 변경
- **외부로 나가는 모든 행위**: 앱인토스 콘솔 등록·검수 제출, 스토어·등급분류 신청, 외부 게시, PR 생성, 기본 브랜치 머지
- 출시, Go/Kill 판단

### 오너 에스컬레이션 형식
```
[결정 필요] 제목
- 배경: 한두 줄
- 선택지: A / B / (C)
- PM 추천: A. 이유
- 기한: 이 결정이 막는 작업
```
여러 건은 한 번에 묶어서 묻습니다. 결정을 기다리는 동안에는 그 결정과 무관한 작업을 계속 진행합니다.

## 5. 고정 원칙 (변경하려면 오너 승인 필요)
- 서버 0원 구조입니다. 앱인토스의 Storage, 게임센터 리더보드, 광고 SDK, 일반 공유만 사용합니다. 공유 리워드는 2026-10-23에 종료되어 쓰지 않습니다(D-021).
- 앱인토스는 다크 모드를 지원하지 않으므로 라이트 모드 기준으로 디자인합니다.
- 외부 지출은 Claude 사용료와 필수 행정 비용으로 한정합니다.
- 게임 결과(성공·점수·랭킹)에 따른 토스포인트 지급과 확률형 보상은 금지입니다.
- 톤은 '서로 눈치 보는 공감 코미디'입니다. 비하·폭언·성희롱·외모나 성별·나이 고정관념은 쓰지 않습니다. 실존 기업, 상표, 인물은 등장시키지 않습니다.
- 성별은 다양하게 등장시키되(D-088), 성별에 따른 차이는 화장실·탈의실 같은 시설·제도 기반 케이스로만 표현하고 남녀 유불리는 대칭으로 둡니다(D-087).
- 에셋은 오리지널이거나 상업적 이용이 허용된 라이선스만 사용합니다(CC-NC 금지). 모든 외부 에셋은 `compliance/asset-license-ledger.md`에 기록합니다.
