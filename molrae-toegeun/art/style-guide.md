# 몰래퇴근 도트 스타일 가이드 v1

- 작성: mt-pixel-artist (T-103), 2026-11-22
- 관련 결정: D-007(일반 스프레드시트), D-009(소품·실루엣으로 구분), D-011(코드 생성 + 오너 보정), D-014(톤 시안 3종 중 오너 선택)
- 상태: **톤 미정.** 오너가 A·B·C 중 하나를 고르면 해당 `palette-X.json`을 `palette.json`으로 확정하고 이 문서의 §3을 갱신합니다.

## 1. 해상도와 격자

| 항목 | 규격 |
|---|---|
| 타일 | 16×16. 배경 타일은 가로로 이어 붙여도 이음새가 맞아야 함 |
| 캐릭터 | 16×24(앉은 자세 기준). 서 있는 자세도 16×24 안에서 해결 |
| 큰 오브젝트 | 16의 배수 폭: 책상 32×16, 파티션·화분·서류함 16×32 |
| 기준 화면 | 192×96(12×6타일) 장면 단위. 게임에서는 정수 배율(×3~×5)로만 확대, 보간 끔(nearest) |
| 시점 | **옆모습 단면(사이드뷰).** 좌·우 1축 이동(검토 보고서 §3-2)과 맞춤. 모니터 화면만 관객 쪽으로 보여 주는 관례를 허용 |
| 접지선 | 바닥에 놓이는 오브젝트의 마지막 픽셀 행을 장면 y=87에 맞춤(벽 걸레받이보다 아래에 놓여 깊이감) |

## 2. 픽셀 원본과 생성 파이프라인

- 원본: `art/src/sprites/*.json` — 한 파일에 스프라이트 하나, 프레임 여러 개. 각 프레임은 **문자 격자**(한 글자 = 한 픽셀).
- 문자 → 팔레트 **역할** 매핑: `art/src/legend.json`. 원본에는 색이 아니라 역할(`outline`, `skin`, `suit` …)만 적으므로 팔레트 파일만 바꾸면 톤 전체가 바뀝니다.
- 장면: `art/src/scenes/office-zone.json` — 타일 맵 + 오브젝트 배치(그리는 순서 = 배열 순서). 오브젝트별 `swap`(역할 치환)과 `flip`(좌우 반전)을 지원합니다.
- 생성: `python3 art/tools/pixelgen.py` (Python 3.8+ 표준 라이브러리만 사용, PNG 인코더 내장, Pillow 불필요)
  - `--check`: 원본 검사(행 길이, 미정의 문자)만
  - `--tone a --out game/assets/sprites`: 확정 톤을 게임 에셋으로 출력
  - 같은 입력이면 같은 바이트가 나옵니다(재실행 sha256 일치 확인).
- 출력: `art/build/tone-X/`(개별 PNG, `sheet.png`, `sheet.json` = Phaser JSON Hash 아틀라스, 장면 PNG), `art/preview/`(4배 확대).
- 오너 보정 방법: JSON의 문자를 직접 고치고 스크립트를 다시 돌립니다. PNG를 직접 편집하면 다음 생성 때 덮어써지므로, PNG로 보정했다면 알려 주세요(격자로 역변환해 원본에 반영).

### 문자 키(legend)
| 문자 | 역할 | 문자 | 역할 |
|---|---|---|---|
| `.` | 투명 | `O` | outline 외곽선 |
| `D` `M` `L` `W` | 무채색 4단 + 흰색 | `S` `s` | 피부 / 피부 그림자 |
| `H` | 머리카락 | `P` `p` | 플레이어 옷 / 그림자 |
| `B` `b` | 상사·NPC 옷 / 그림자 | `Q` `q` | 벽 / 벽 그림자 |
| `F` `f` | 바닥 / 바닥 그림자 | `T` `t` | 나무(책상) / 그림자 |
| `C` `c` | 쿨톤(파티션 천, 유리) / 그림자 | `G` `g` | 초록(식물, 스프레드시트 강조) / 그림자 |
| `R` | point(위험·상사 표식: 사원증 줄) | `Y` | point2(명패, 보상) |

## 3. 팔레트(톤 시안 3종, 각 24색 고정)

| 시안 | 파일 | 특징 |
|---|---|---|
| A 따뜻한 파스텔 | `palette-a.json` | 낮은 채도·밝은 명도, 자두빛 갈색 외곽선. 아늑하고 귀여운 일상물 |
| B 선명한 고대비 | `palette-b.json` | 높은 채도·강한 명암, 남색 외곽선. 작은 화면에서 가장 또렷함 |
| C 모노톤+포인트 | `palette-c.json` | 청회색 단계 위에 주황 포인트(`point`)는 상사·경고에만 사용. 위험 판독이 가장 빠름 |

규칙
- 팔레트는 24색에서 늘리지 않습니다. 새 색이 필요하면 기존 역할을 재사용하거나 PM과 협의합니다.
- 순수 검정(#000)과 순수 회색은 외곽선에 쓰지 않고, 톤마다 색이 섞인 가장 어두운 색을 씁니다.
- 앱인토스는 라이트 모드 기준이므로 배경(벽)은 밝게, 캐릭터는 그보다 어둡게 두어 대비를 확보합니다.
- `point`(빨강·주황)는 **상사/위험** 신호 전용입니다. 플레이어 쪽 소품에는 쓰지 않습니다(머그 로고 1픽셀 정도는 예외).

## 4. 외곽선 규칙

- 캐릭터·가구·소품: 1px `outline` 외곽선을 **닫힌 형태**로 둘러 배경과 분리합니다.
- 안쪽 경계(팔과 몸통 등)는 외곽선 대신 그림자색으로 나눕니다. 눈은 1×2 외곽선색 점.
- 배경 타일(벽·바닥)은 외곽선 없이 명암 점으로만 질감을 줍니다. 창틀·걸레받이 같은 구조선만 외곽선색을 씁니다.
- 대각선은 1:1 또는 1:2 계단만 쓰고, 2px 이상 뭉친 '재기(jaggy)'를 남기지 않습니다.
- 안티에일리어싱, 반투명 픽셀은 쓰지 않습니다(알파는 0 또는 255).

## 5. 명암 단계

- 광원: **왼쪽 위.** 오른쪽·아래가 그림자.
- 재질마다 기본 2단(기본색 + 그림자) + 외곽선. 금속·화면만 하이라이트(`L`/`W`) 1단 추가로 최대 3단.
- 피부는 2단(턱 밑, 귀). 머리카락은 1단(작은 크기에서 덩어리로 읽히도록).
- 벽·바닥 질감 점은 타일당 4개 이하, 규칙 간격(시선 분산 방지).

## 6. 캐릭터 베이스 바디 2종

두 체형은 **실루엣 차이**일 뿐 나이·성별을 나타내지 않습니다. 같은 역할을 어느 체형으로도 만들 수 있습니다.

| | 바디 A '콩' (둥근형) | 바디 B '두부' (사각형) |
|---|---|---|
| 머리 | 11px 폭, 둥근 윗머리 | 11~12px 폭, 평평한 윗머리 |
| 몸통 | 5px 높이, 좁은 어깨 | 6px 높이, 넓은 어깨(1px 더 넓음) |
| 머리:몸 | 약 1:1(귀여운 2등신) | 약 1:1.2 |
| 사용 예 | 플레이어, 선배, 공범 동료, 인사팀 | 팀장, 임원, 경비팀, 고자질 동료 |

- 원본 예시: `src/sprites/char-player.json`(바디 A), `src/sprites/char-boss.json`(바디 B).
- 파생: 팔레트 역할 치환(`swap`: `shirt`→`suit` 등)과 머리 모양 3종(짧은, 묶은, 덮은 머리), 소품 레이어로 9종 이상을 만듭니다.
- 상태 애니메이션은 4종으로 한정: `idle`(대기), `work`(일하는 척 — 타이핑 2프레임), `slack`(땡땡이), `caught`(들킴). 상사는 `back`(등 돌림) + `tell`(전조) + `look`(돌아봄).
- 이번 시안에서 만든 프레임: `player/work_0~1`, `teamlead/back_0`(등 돌림), `teamlead/back_1`(전조: 어깨가 1px 들썩).

## 7. 상사·NPC 구분: 소품과 실루엣 (D-009)

| 캐릭터 | 바디 | 핵심 소품(1~2개만) | 실루엣 포인트 |
|---|---|---|---|
| 플레이어 | A | 초록 사원증 줄, 머그컵 | 낮은 등받이 의자 |
| 선배 | A | 머리 위 '…' 말풍선 아이콘, 파란 사원증 줄 | — |
| 팀장 | B | **빨간 사원증 줄(point)**, 명패, 책상 전화기 | **높은 등받이 의자** |
| 임원 | B | 넥타이 + 서류 가방 | 서 있는 자세, 시선 콘 |
| CEO | B | 금색(point2) 배지 + 손에 든 커피 | 화면 등장 시 주변 '얼음' 연출 |
| 경비팀 | B | 모자 챙 + 손전등(시선 콘) | 모자 실루엣 |
| 고자질 동료 | B | 메모지 클립보드 | 몸을 앞으로 기울인 자세 |
| 공범 동료 | A | 종이컵 두 개 | — |
| 인사팀 | A | 출입 명부 바인더 + 노란 줄 | — |

- 직급·위험도는 사원증 줄 색으로 일관되게: 플레이어·동료 `green`, 선배 `cool`, 팀장 `point`, 임원 이상 `point2`.
- 같은 화면에 소품이 겹치면 **위험한 쪽이 point 색을 가집니다.**

## 8. '일하는 척' 화면 (D-007)

- 모니터에는 **일반 스프레드시트**만: 초록 제목줄 1행 + 회색 격자 + 강조 셀 1개. 특정 제품의 리본 메뉴·아이콘·로고·글꼴을 흉내 내지 않습니다.

## 9. 금지사항

- 실존 기업 로고·상표·제품 UI, 실존 인물, 유명 IP 캐릭터를 연상시키는 형태·색 조합.
- 나이·성별·외모 고정관념으로 역할 구분(대머리=상사, 치마=여직원, 주름=임원 등). 역할은 소품과 실루엣으로만.
- 흡연·음주 소품(담배, 술병). 흡연실은 '옥상 바람쐬기', 음주는 '건배 턴'으로 추상화(D-008).
- 비하·폭력 묘사, 땀·눈물의 과한 표현.
- 팔레트 밖 색, 반투명·안티에일리어싱 픽셀, 비정수 배율 확대.
- CC-NC 등 상업 이용 불가 라이선스 에셋. 외부 에셋은 직접 넣지 않고 PM에게 후보와 라이선스를 제안.
