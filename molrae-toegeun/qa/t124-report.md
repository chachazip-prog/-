## D-038 근거 자료: 전조 없이 시선에 들어오는 빈도

분류 기준은 `tests/lib/observe.ts`입니다. 시선이 시작된 스텝에서 NPC가 tell 없이 방향을 바꿨고, 바꾸기 전 방향으로는 플레이어가 보이지 않았던 경우를 셉니다.

| 측정 | 무작위 탭 300판 | 직진 봇 | 위장 봇 | 느린 초보 |
|---|---|---|---|---|
| 전조 없는 NPC 방향 전환(전체) | 분당 32.6회 (모퉁이 5793, 재출발 3987) | | | |
| 그중 플레이어가 새 시선에 바로 들어감 | 168회 (모퉁이 126, 재출발 42) | 판당 0.12 | 판당 0.14 | 판당 0.20 |
| 1회 이상 겪은 판 | | 11.6% | 14.3% | 19.4% |
| 전체 시선 시작 중 비중 | 32.7% | 8.1% | 11.7% | 13.3% |
| 전체 의심 상승 중 비중 | | 12.9% | 13.2% | 14.8% |
| 이 원인으로 들킨 판 (기본 수치) | | 0 | 0 | 0 |
| 이 원인으로 들킨 판 (의심 ×3 스트레스) | | 4/1000 | 26/1000 | 16/1000 |
| 말걸기 시작(즉시 돌아봄, BUG-002) 판당 | | 0.36 | 0.36 | 0.35 |

해석:
- 지금 수치에서는 레벨이 너무 쉬워서 억울한 들킴이 0건입니다.
- 목표 난이도(적발 10% 안팎)에 가까운 스트레스 변형에서는 들킨 판 중 전조 없는 시선이 원인인 비율이 위장 봇 30.6%, 초보 10.2%입니다.
- D-038 적용(전환 전 tell)은 필요하다고 판단합니다.
- 모든 모퉁이에 tell을 넣으면 분당 30회가 넘는 '!'가 생깁니다. 그래서 새 콘이 플레이어(또는 화면) 쪽을 향할 수 있을 때만 붙이는 D-038의 조건부 방식이 맞습니다.
