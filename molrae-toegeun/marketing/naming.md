## 3. 오너 직접 확인 체크리스트

### 3-1. KIPRIS 상표 검색 (https://www.kipris.or.kr → 상표 검색)

**검색 키워드** (한글·영문·띄어쓰기 변형을 모두 넣습니다. KIPRIS는 칭호(발음) 유사 검색도 지원하니 '유사 검색'도 켭니다.)

| 우선 | 키워드 |
|---|---|
| 1 | `몰래퇴근`, `몰래 퇴근` |
| 1 | `MOLRAE`, `MOLLAE`, `몰래` (단독 선행상표가 있는지) |
| 2 | `몰래칼퇴`, `칼퇴`, `퇴근` + 게임 관련 지정상품 |
| 2 | 대체명 후보(§4): `칼퇴각`, `눈치퇴근`, `퇴근각`, `오늘도칼퇴` |

**확인할 상품류(니스 분류)**

| 류 | 무엇 | 필수 여부 |
|---|---|---|
| **9류** | 게임 소프트웨어, 다운로드 가능한 게임 프로그램, 모바일 앱 | **필수** |
| **41류** | 온라인 게임 제공업, 오락 서비스업 | **필수** |
| 42류 | 소프트웨어 서비스(SaaS) 제공 | 참고 |
| 28류 | 게임용구, 장난감 (굿즈 확장 시) | 선택 |
| 16류 / 25류 | 문구·스티커 / 의류 (굿즈 확장 시) | 선택 |

**판정 기준(1차)**
- 9류·41류에 `몰래퇴근` 또는 발음이 거의 같은 표장이 **등록·출원·공고** 상태 → 대체명 전환(§4) 권장. 이 경우 PM에 즉시 알립니다.
- '거절'·'소멸' 상태만 있음 → 사용은 가능하나, 우리가 출원하면 같은 사유(식별력 부족)로 거절될 수 있습니다.
- 아무것도 없음 → 사용 진행. 출원은 비용(출원료)이 들므로 **오너 판단 사항**입니다(CLAUDE.md §4, 비용 발생). 출원한다면 로고(도트 워드마크)와 결합한 **결합상표**가 문자상표보다 식별력 면에서 유리합니다 [추정, 변리사 확인 권장].

| 후보 | 의도 | 장점 | 단점 |
|---|---|---|---|
| **A. 칼퇴각** | '칼퇴 각 잡는다'. 결과 화면의 '오늘 칼퇴각?'과 연결 | 짧고 공유 문구에 잘 붙음, 웹 검색상 게임명 충돌 없음 | '칼퇴'는 유틸 앱에서 흔히 쓰여 검색 혼잡 |
